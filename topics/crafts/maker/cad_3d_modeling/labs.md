# Operational Verification Labs: Cad 3D Modeling

## Objective & Operational Lab Setup

These laboratory exercises establish verifiable parametric CAD modeling competency through systematic construction, constraint validation, and dimensional tolerance verification. You will build three progressively complex mechanical assemblies using Fusion 360 or FreeCAD, applying geometric constraint theory, parametric dimension propagation, and mechanical fit tolerance engineering. The goal is not conceptual understanding but demonstrated execution: producing fully constrained models that survive dimensional edits without catastrophic constraint failure, export to manufacturing-ready formats, and meet mechanical interference specifications measurable with digital calipers.

Install Fusion 360 (free for hobbyists via Autodesk's personal license) or FreeCAD 0.21+ on a system with GPU acceleration enabled for real-time constraint solver feedback. Fusion 360 provides superior parametric timeline rollback and cloud rendering, while FreeCAD offers open-source flexibility and Python scripting integration. Both will serve these exercises equally well. You will also need digital calipers with 0.01 mm resolution for printed part verification, a desktop FDM printer calibrated to 0.1 mm dimensional accuracy (Prusa i3 MK3S, Ender 3 V2, or equivalent), and PLA filament with measured diameter variance under ±0.03 mm. For Exercise 3, prepare access to mechanical fastener standards tables (ISO 4762 socket head cap screws, DIN 125 washers) and bearing specification sheets (608ZZ skate bearings or 6001-2RS radial ball bearings).

The laboratory methodology mirrors precision machining practice: measure twice, constrain once, verify continuously. Each sketch must achieve fully constrained status (zero degrees of freedom, indicated by black geometry in Fusion 360 or green in FreeCAD) before extrusion or revolution. Dimensional parameters will be defined in a master parameter table, allowing single-point edits to propagate through dependent features without manual rework. You will validate each assembly's mechanical function by exporting STL meshes, slicing with 0.2 mm layer height and 3 perimeters, printing test articles, and physically measuring critical dimensions with calipers. Deviations exceeding 0.15 mm indicate either under-constrained sketches, inappropriate tolerance allocation, or slicer compensation errors requiring systematic diagnosis.

Prepare a structured project directory: `cad_verification_labs/exercise_1_bracket/`, `exercise_2_gearbox/`, and `exercise_3_bearing_block/`. Each subdirectory will contain the native CAD file, exported STEP AP214 for interoperability verification, STL meshes for 3D printing, a parameter spreadsheet tracking all dimension variables, and a measurement log recording caliper readings against design intent. This forensic documentation enables root-cause analysis when prints fail dimensional inspection, distinguishing between CAD modeling errors, slicing artifacts, and printer mechanical deficiencies.

## Exercise 1: Foundational Practical Implementation

You will design a fully parametric right-angle mounting bracket with four bolt holes, a rectangular mounting face, and a perpendicular flange featuring a centered slot for adjustable positioning. This exercise establishes core constraint discipline: geometric relations (perpendicular, parallel, concentric, symmetric), dimensional constraints (linear, angular, radial), and construction geometry usage. The bracket must survive aggressive dimensional edits—doubling flange height, halving base thickness, or relocating bolt patterns—without constraint solver failure or manual sketch repair.

Begin by creating a new component in Fusion 360 (Component → Create) or a new Part in FreeCAD (Part Design → Create Body). Activate the XY plane and enter Sketch mode. Define parameters first, before drawing geometry. Open the parameter table (Modify → Change Parameters in Fusion; Spreadsheet workbench in FreeCAD) and establish the master dimensional variables. Create `base_length = 80 mm`, `base_width = 40 mm`, `base_thickness = 6 mm`, `flange_height = 50 mm`, `flange_thickness = 6 mm`, `bolt_hole_diameter = 5.2 mm` (clearance for M5 screws with 5.0 mm nominal diameter), `bolt_hole_inset = 10 mm` (distance from edge to hole center), `slot_width = 6.2 mm` (clearance for M6 bolts), and `slot_length = 30 mm`. These values are not arbitrary; they reflect mechanical design heuristics: clearance holes exceed fastener diameter by 0.2 mm for slip-fit assembly, edge insets equal twice the hole diameter to prevent stress concentration fractures, and flange thickness matches base thickness for uniform bending stiffness.

Draw the base profile as a rectangle centered on the origin. Use the Center Rectangle tool to place the geometric center at (0, 0), then dimension the width and length using parameter names rather than numeric literals: select the horizontal edge, press D for dimension, and type `base_length` in the value field. Repeat for width with `base_width`. This parameter binding ensures that editing `base_length` in the parameter table instantly updates the sketch geometry. Apply a horizontal constraint to the bottom edge and a vertical constraint to the left edge, locking orientation to the global coordinate system. The rectangle should now display as fully constrained (black lines, no blue underconstrained indicators).

Add four bolt holes using the Circle tool, placing centers at positions calculated from parameters. The first hole sits at (`base_length/2 - bolt_hole_inset`, `base_width/2 - bolt_hole_inset`). In Fusion 360, you can directly enter expressions in dimension fields; in FreeCAD, use construction lines dimensioned parametrically to locate circle centers. Diameter each circle to `bolt_hole_diameter`. To enforce symmetric spacing without manually calculating four positions, use rectangular pattern mirroring: draw only the top-right hole, then apply Mirror constraints across vertical and horizontal construction lines passing through the origin. This geometric dependency means editing the single hole's position automatically updates all four, maintaining quadrilateral symmetry under dimensional changes.

Extrude the base sketch upward by `base_thickness` as a solid body. Activate the top face and create a new sketch. Draw a vertical construction line coincident with the midpoint of the base's long edge; this construction geometry serves as a reference axis. Draw the flange profile as a rectangle extending from the construction line, dimensioned `flange_thickness` wide and `flange_height` tall. Apply a symmetric constraint to make the construction line the flange's centerline. Add a centered slot using two circles connected by tangent lines: place circles `slot_length/2` apart vertically along the construction line, radius `slot_width/2`, then draw tangent lines connecting their leftmost and rightmost quadrant points. Trim the interior circle arcs, leaving a slot profile. Dimension the circle separation to `slot_length - slot_width` (accounting for radius overlap), and verify full constraint.

Extrude the flange profile perpendicular to the base (90° to the XY plane) by a distance equal to `base_thickness`, creating a continuous L-shaped solid. The parametric timeline now contains three feature operations: base extrusion, sketch on top face, flange extrusion. Perform the stress test: edit `flange_height` from 50 mm to 100 mm. The flange should elongate without constraint failure, solver errors, or sketch corruption. Edit `bolt_hole_inset` from 10 mm to 15 mm; all four holes should migrate inward symmetrically. If any operation triggers warnings ("sketch became underconstrained" or "solve failed"), diagnose which constraints broke. Common failure modes include coincident constraints referencing deleted construction geometry, or dimensions applied to derived edges rather than master sketch entities.

Export the bracket as both STEP AP214 (File → Export, select STEP format with "export as single body" enabled) and STL mesh (resolution 0.01 mm chord height, 15° angular deviation). Load the STL in your slicer (Cura, PrusaSlicer, or SuperSlicer), orient the base flat on the build plate, enable supports for the flange overhang if your printer cannot bridge 50 mm reliably, and slice with 0.2 mm layer height, 3 perimeters, 20% cubic infill. Print the bracket. After cooling, measure critical dimensions with calipers: base length and width (target ±0.1 mm), bolt hole diameters (target 5.2 mm ±0.1 mm, ensuring M5 screws fit with rotational clearance), and slot width (target 6.2 mm ±0.15 mm). Record deviations in your measurement log. If bolt holes print undersized (common with FDM due to elephant's foot and layer squish), increase `bolt_hole_diameter` by 0.2 mm and re-slice. This iterative calibration between CAD intent and printed reality is the core feedback loop of mechanical design.

Verify parametric integrity by creating a design variation: edit `base_length` to 60 mm, `flange_height` to 70 mm, and `slot_length` to 40 mm in a single operation. The model should regenerate without errors. Export, print, and measure this variant to confirm tolerance consistency across dimensional ranges. The bracket is operationally verified when you can specify arbitrary dimensions within sane limits (10 mm to 200 mm for lengths, 4 mm to 12 mm for thicknesses) and produce physically accurate prints within 0.15 mm of design intent.

## Exercise 2: Parameter Variation & Empirical Analysis

You will design a two-stage spur gear reduction gearbox with parametric gear tooth profiles generated from module, pressure angle, and tooth count variables. This exercise demonstrates constraints operating at the mathematical definition level: involute curve generation, pitch circle tangency, center distance calculation from gear ratios, and backlash tolerance allocation. The gearbox will be printed as separate components, assembled with steel shafts and 608ZZ bearings, and tested for kinematic function and gear mesh quality under load.

Begin with gear theory fundamentals that directly inform constraint decisions. Spur gear geometry is defined by the module ($m$, millimeters per tooth), pressure angle ($\alpha$, typically 20°), and number of teeth ($N$). Pitch diameter follows $D_p = m \cdot N$, addendum (tooth height above pitch circle) equals $m$, and dedendum (depth below pitch circle) is $1.25m$ to provide clearance. Center distance between meshing gears is $C = (D_{p1} + D_{p2})/2 = m(N_1 + N_2)/2$. For a 3:1 reduction, if the input pinion has $N_1 = 12$ teeth and module $m = 2$ mm, the output gear requires $N_2 = 36$ teeth, yielding $C = 2(12 + 36)/2 = 48$ mm center distance. These relationships must be encoded as parametric constraints, not manually calculated dimensions, so that editing module or tooth count instantly recalculates center distance without breaking the gearbox housing geometry.

Create a new component named `gearbox_housing`. Define parameters: `module = 2.0 mm`, `pressure_angle = 20 deg`, `input_teeth = 12`, `intermediate_teeth = 36`, `output_teeth = 15`, `output_large_teeth = 45`, `shaft_diameter = 8.0 mm` (for 8 mm hardened steel rod), `bearing_outer_diameter = 22.0 mm` (608ZZ specification), `bearing_thickness = 7.0 mm`, `wall_thickness = 4.0 mm`, and `backlash = 0.2 mm`. Calculate dependent parameters: `stage1_center_distance = module * (input_teeth + intermediate_teeth) / 2`, `stage2_center_distance = module * (intermediate_teeth + output_teeth) / 2`. Note that `intermediate_teeth` appears in both stages because the intermediate shaft carries both the driven gear of stage 1 and the drive pinion of stage 2, forming a compound gear train.

Generate gear profiles using a dedicated add-in or script. Fusion 360 users should install the SpurGear script from the Autodesk App Store, which procedurally generates involute profiles from module and tooth count. FreeCAD users will use the FCGear workbench: activate it (View → Workbench → FCGear), then Gear → Involute Gear, entering module, tooth count, pressure angle, and helix angle (0° for spur gears). Generate four gears: input pinion (12 teeth), stage 1 output (36 teeth), stage 2 pinion (15 teeth, same shaft as 36-tooth gear), and stage 2 output (45 teeth). Each gear body should be extruded 10 mm thick with a central bore sized to `shaft_diameter + 0.1 mm` for a slip fit on the steel shaft. Add a keyway slot (2 mm wide, 1.5 mm deep) along the bore to lock the gear rotationally via a metal key.

Design the gearbox housing as a two-part clamshell. Sketch the base profile on the XY plane: a rectangle 150 mm long by 80 mm wide with rounded corners (5 mm radius fillets). Place bearing pockets at positions calculated from center distances: input shaft at (20, 40), intermediate shaft at (`20 + stage1_center_distance`, 40), output shaft at (`20 + stage1_center_distance + stage2_center_distance`, 40). Each pocket is a circle with diameter `bearing_outer_diameter + 0.2 mm` (press fit for bearing), depth `bearing_thickness + 0.5 mm` (allowing the bearing to sit slightly recessed). Use construction lines radiating from the origin to each bearing center and dimension these lines parametrically; this constraint topology ensures that editing gear teeth (which changes center distance) automatically relocates bearing pockets without manual sketch edits.

Extrude the base 20 mm tall, then shell the interior by `wall_thickness`, leaving the top face open. Add mounting bosses at the four corners: 8 mm diameter cylindrical protrusions extending 5 mm above the base, centered 10 mm from each corner, with 4.2 mm through-holes for M4 mounting screws. Create the top cover as a mirrored component: copy the base sketch, remove the bearing pockets (the cover simply caps the gearbox), add M4 clearance holes aligned with the base's bosses, and extrude 6 mm thick. Apply a 1 mm clearance offset to the cover's mating surface so it nests onto the base without interference.

Assemble the gearbox digitally before printing. Create an assembly (Fusion 360: Design → New Component, set to "Do Not Capture Design History" for performance; FreeCAD: Assembly4 workbench). Insert the base, then add the input pinion, constraining its central bore axis to the input bearing pocket center and applying a revolute joint (rotation about the shaft axis). Insert the stage 1 output gear on the intermediate shaft, offset axially by 12 mm to avoid collision with the input pinion. Add the stage 2 pinion on the same shaft, coaxial with the stage 1 gear. Insert the output gear on the output shaft. Apply gear mate constraints (Fusion 360: "Tangent" relation between pitch circles; FreeCAD: "Gear" constraint in the Assembly4 workbench) between meshing gears. The assembly should allow continuous rotation of the input shaft while driving the output through the 9:1 reduction (3:1 from stage 1, 3:1 from stage 2).

Test the parametric robustness by editing module from 2.0 mm to 2.5 mm. All gear profiles should regenerate with updated dimensions, bearing pockets should migrate to new center distances, and the assembly should maintain mesh relationships. If constraints break, diagnose whether construction geometry was orphaned (bearing centers lost their reference), or if dimensions were applied to derived edges rather than sketch parameters. Fix errors, then restore module to 2.0 mm.

Export each component as STL. Print the gears with 100% infill and 0.1 mm layer height for maximum tooth surface accuracy, oriented flat on the build plate to align layer lines with the pitch circle (minimizing tooth flank roughness perpendicular to the direction of sliding contact). Print the base and cover with 3 perimeters and 30% gyroid infill. Acquire 8 mm diameter steel rod cut to 70 mm lengths (three shafts), four 608ZZ bearings, and M4×20 mm socket head cap screws with nuts. Press bearings into the pockets (they should require firm thumb pressure; if loose, increase pocket diameter by 0.1 mm and reprint). Slide gears onto shafts with keyways aligned, insert shafts into bearings, and bolt the cover down.

Measure gear backlash empirically: hold the output shaft stationary, rotate the input shaft forward until contact, mark the angular position with a marker, then rotate backward until contact and measure the angular displacement. Convert to linear backlash at the pitch circle: $B_{\text{linear}} = B_{\text{angular}} \cdot (D_p / 2)$ in radians. Target backlash is 0.2–0.4 mm at the pitch circle. Excessive backlash (>0.6 mm) indicates under-extruded teeth or incorrect center distance; measure printed center distance with calipers and compare to `stage1_center_distance` parameter. Insufficient backlash (<0.1 mm) causes binding; increase the `backlash` parameter by 0.1 mm, regenerate gears, and reprint.

Test under load by attaching a hand drill to the input shaft and a spring scale to the output shaft via a 50 mm radius arm. Measure torque multiplication: apply 2 Nm input torque (measured via drill clutch setting), measure output force on the spring scale, calculate output torque as $T_{\text{out}} = F \cdot r$ where $r = 50$ mm. Theoretical mechanical advantage is 9:1, so 2 Nm input should yield 18 Nm output; measured values within 80% of theoretical indicate acceptable efficiency (losses from bearing friction, gear mesh sliding, and material flex). Failure modes include stripped teeth (indicating insufficient wall thickness; increase gear extrusion from 10 mm to 15 mm) or cracked housing (increase `wall_thickness` by 1 mm). Record all measurements in a data table correlating parameter changes with mechanical performance.

## Exercise 3: Stress Testing, Boundary Failure & Recovery Protocol

You will design a pillow block bearing housing for a 6001-2RS radial ball bearing supporting a rotating shaft under 50 N radial load, then systematically introduce constraint failures, analyze solver error diagnostics, and recover the model from broken states without starting over. This exercise trains operational resilience: CAD models fail in production environments due to dimension changes, imported geometry conflicts, or feature reordering during design iteration. You must develop diagnostic fluency—reading constraint solver error messages, interpreting sketch state indicators, and applying targeted repairs rather than deleting and rebuilding.

The pillow block design embeds mechanical engineering decisions as constraints: bearing press-fit tolerance (ISO H7/g6, -0.005 to -0.015 mm interference), bolt hole positioning per ISO 4762 standards (minimum edge distance 1.5× hole diameter), and material stress concentration mitigation (fillet radii ≥0.3× wall thickness at re-entrant corners). These are not styling choices but structurally necessary relationships that must survive model edits.

Create a new component `bearing_block_6001`. Define parameters: `bearing_bore = 12.0 mm`, `bearing_outer_diameter = 28.0 mm`, `bearing_width = 8.0 mm`, `press_fit_interference = -0.010 mm` (negative indicates interference), `housing_width = 40.0 mm`, `housing_height = 35.0 mm`, `housing_depth = bearing_width + 5.0 mm`, `base_thickness = 8.0 mm`, `wall_thickness = 5.0 mm`, `mounting_hole_diameter = 6.5 mm` (M6 clearance), `mounting_hole_spacing = 60.0 mm`. Calculate `bearing_pocket_diameter = bearing_outer_diameter + press_fit_interference` (yields 27.99 mm for a tight fit requiring thermal expansion or arbor press installation).

Sketch the base profile on the XY plane: a rectangle `housing_width × housing_depth` centered on the origin. Extrude upward `base_thickness`. Sketch the vertical walls on the top face: two rectangles extending from the left and right edges of the base, each `wall_thickness` wide and `housing_height` tall, leaving a U-shaped channel. Extrude these walls upward `housing_height`. Add the bearing pocket as a circle centered at (0, `housing_height - bearing_outer_diameter/2 - wall_thickness`) with diameter `bearing_pocket_diameter`, extruded as a hole through the vertical walls. Add mounting holes at (±`mounting_hole_spacing/2`, `housing_depth/2`), diameter `mounting_hole_diameter`, through the base.

Apply fillets: 2 mm radius at the base-to-wall intersections (re-entrant corners where stress concentrates under bending load), 1 mm radius on all external edges (for handling safety and paint adhesion). Constrain the bearing pocket center using a construction line perpendicular to the base, dimensioned from the top edge by `wall_thickness + bearing_outer_diameter/2`. This geometry dependency ensures that editing `bearing_outer_diameter` automatically repositions the pocket to maintain constant wall thickness above.

Now introduce systematic constraint failures to train recovery protocols. Save the working model as `bearing_block_baseline.f3d`. Edit the parametric timeline to reorder features: drag the fillet operation before the bearing pocket hole. The solver will fail because fillets reference edges created by the hole operation, which now does not exist yet in the timeline. The error message will state "cannot create fillet on edge that does not exist." Diagnosis: feature dependency graph is acyclic; a feature cannot reference geometry from a later feature. Recovery: drag the fillet operation back to its original position after the hole. This failure mode mirrors real-world scenarios where importing STEP files disrupts the parametric timeline, requiring manual feature reordering.

Introduce an underconstrained sketch failure. Edit the base sketch and delete the horizontal dimension constraint. The rectangle becomes underconstrained (blue color in Fusion 360, orange in FreeCAD). Attempt to extrude; the solver allows it but warns "sketch is not fully constrained." Edit `housing_width` in the parameter table from 40 mm to 50 mm. The sketch does not update because the missing dimension means `housing_width` has no binding to geometry. Recovery: open the sketch, select the horizontal edge, apply a dimension constraint, and enter `housing_width`. The geometry snaps to 50 mm. This trains the discipline of never proceeding past underconstrained sketches, even if extrusion succeeds, because future parametric edits will silently fail.

Introduce an over-constrained conflict. Add a second dimension to the bearing pocket circle: diameter `bearing_pocket_diameter` (already applied) and radius `14.0 mm` (contradictory if `bearing_pocket_diameter ≠ 28.0 mm`). The solver throws "over-constrained sketch" error. Diagnosis: two conflicting dimensions define the same geometric degree of freedom. Recovery: delete one dimension. In practice, over-constraints arise when importing external geometry with locked dimensions, then adding parametric dimensions. The rule: one dimension per degree of freedom.

Introduce a reference geometry deletion failure. Create a construction line from the origin to the bearing pocket center, then dimension the pocket's vertical position relative to this line. Delete the construction line. The dimension orphans, and the sketch becomes underconstrained. Recovery: recreate the construction line with identical position constraints, or replace the reference with a direct dimension from the base edge. This mirrors scenarios where imported reference geometry disappears after STEP reimport, breaking dependent constraints.

Test tolerance stack-up under extreme parameter variation. Edit `bearing_outer_diameter` from 28.0 mm to 50.0 mm (simulating a different bearing series, e.g., 6205-2RS). The bearing pocket diameter updates via the `press_fit_interference` formula. Check that the pocket does not intersect the mounting holes (indicating insufficient housing width) by measuring the distance from the pocket edge to the nearest hole edge: it must exceed `wall_thickness`. If interference occurs, the model is geometrically invalid. Recovery: add a conditional parameter: `housing_width = max(bearing_outer_diameter + 20.0 mm, 40.0 mm)`, ensuring the housing automatically enlarges to accommodate larger bearings.

Print the bearing block with 100% infill and 4 perimeters for structural rigidity. Measure the bearing pocket diameter with calipers; target 27.99 mm but accept 27.90–28.05 mm (the interference must be sufficient for press-fit but not so tight that the printed plastic cracks under installation force). Heat the bearing in boiling water (100°C) to expand the outer race by ~0.05 mm thermal expansion, then immediately press into the pocket. The bearing should seat flush with the housing face. If it protrudes or sits loose, the pocket diameter is incorrect; adjust `press_fit_interference` by ±0.05 mm and reprint.

Test radial load capacity by mounting the block to a rigid surface via the base holes, inserting a 12 mm shaft through the bearing, and applying perpendicular force via a spring scale attached 100 mm from the bearing center. Measure deflection with a dial indicator at the shaft tip. Acceptable deflection under 50 N is <0.5 mm; excessive deflection indicates insufficient wall thickness (increase to 6 mm) or inadequate base thickness (increase to 10 mm). Catastrophic failure (cracked walls) indicates stress concentration at unfilleted corners; verify all re-entrant corners have ≥2 mm fillets. This empirical validation closes the loop: CAD intent → physical article → measured performance → parameter refinement.

## Operational Reference Guide & Diagnostic Checklist

**Parametric Constraint Priority Hierarchy:**  
Master parameters (module, bearing diameter, material thickness) are defined first and govern dependent dimensions. Derived parameters (center distances, clearances) calculate from master values using formulas. Sketch geometry binds to parameters via dimension constraints, never numeric literals. This hierarchy ensures single-point editing propagates changes throughout the model without breaking dependencies.

**Constraint Solver Diagnostic Codes:**  
- "Sketch underconstrained": geometry has remaining degrees of freedom (translation, rotation). Fix: add dimension or geometric constraints (parallel, perpendicular, concentric) until sketch turns fully black (Fusion) or green (FreeCAD).  
- "Sketch overconstrained": conflicting dimensions or redundant geometric relations. Fix: delete one conflicting constraint. Use "Show Constraints" to visualize all active relations.  
- "Cannot create feature on nonexistent geometry": feature references geometry from a later timeline operation. Fix: reorder features in the timeline so dependencies precede dependents.  
- "Fillet/chamfer failed": edge blend exceeds material thickness or intersects adjacent features. Fix: reduce fillet radius or increase wall thickness.

**Tolerance Allocation Guidelines for FDM Printing:**  
- Clearance fits (rotating shafts in bearings): add 0.15–0.25 mm to hole diameter.  
- Sliding fits (drawer slides, linear rails): add 0.1–0.15 mm to slot width.  
- Press fits (bearings in pockets, pins in holes): subtract 0.005–0.015 mm from pocket diameter.  
- Thread engagement (tapped holes): subtract 0.2 mm from nominal thread diameter (e.g., M5 tap into 4.8 mm printed hole).

**Critical Measurement Verification Points:**  
After printing, verify with calipers: hole diameters (check at top, middle, bottom of hole for elephants-foot taper), slot widths (measure at widest point), wall thicknesses (measure between exterior and interior surfaces), and feature spacing (center-to-center distances for bolt patterns). Deviations >0.15 mm indicate print defects (underextrusion, belt skipping) or CAD modeling errors (wrong parameter values, broken constraints). Correlate measurements with parameter table to identify which value to adjust.

**Slicer Compensation Settings:**  
Horizontal expansion (X/Y compensation) corrects for material squish: set to -0.1 mm to shrink exterior perimeters slightly, improving hole accuracy. Z-axis compensation corrects for first-layer squish: if first layer is over-extruded, increase first-layer height from 0.2 mm to 0.25 mm. Enable "Detect thin walls" to prevent slicer from omitting features thinner than one nozzle width. Set minimum feature size to 0.4 mm (one nozzle pass) to avoid discretization errors on small geometry.

**Mechanical Assembly Validation Protocol:**  
1. Dry-fit all components before final assembly to verify clearances.  
2. Measure actual fastener dimensions (bolt diameter, nut width) with calipers; nominal M5 bolts may measure 4.92–5.08 mm.  
3. Test bearings for smooth rotation before pressing into pockets; reject any with gritty feel (contaminated grease).  
4. Apply Loctite 243 (medium-strength threadlocker) to fasteners in high-vibration applications.  
5. Torque fasteners to specification: M3 to 0.5 Nm, M4 to 1.2 Nm, M5 to 2.0 Nm, M6 to 3.5 Nm. Over-tightening cracks printed plastic.

**Constraint Recovery Decision Tree:**  
If sketch becomes underconstrained → identify missing dimension or geometric relation → apply fix constraint.  
If sketch becomes overconstrained → use "Show Constraints" to find conflicting pair → delete redundant constraint.  
If feature fails to regenerate → check timeline order → move dependent features after their references.  
If parametric edit has no effect → verify dimension is bound to parameter (not numeric literal) → re-dimension using parameter name.  
If entire model corrupts → roll back to last known good state via timeline slider → isolate failure by testing parameter edits incrementally.

This operational framework reduces CAD modeling from artisanal trial-and-error to reproducible engineering protocol, where constraint failures become diagnostic opportunities rather than project-ending disasters.
