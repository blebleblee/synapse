# Hands-On Operational Lab: Custom Decals
## Objective & Lab Prerequisites

### Objective
The objective of this lab is to guide you through the process of creating and applying custom decals to LEGO models. This includes designing the decals, preparing them for printing, and applying them to your LEGO creation. By the end of this lab, you will have a comprehensive understanding of the tools and techniques required to enhance your LEGO models with custom decals.

### Lab Prerequisites
- A computer with a graphics design software (e.g., Adobe Photoshop, GIMP).
- A printer capable of printing on vinyl or paper.
- A vinyl cutter or scissors for cutting decals.
- A LEGO model to apply the decals to.
- Adhesive spray or transfer tape for applying decals.
- Basic understanding of using a graphics design software.

## Exercise 1: Exploration, Diagnostics & System State Inspection

### Step 1: Designing the Decal
1. Open your graphics design software and create a new file with the dimensions of your LEGO piece.
2. Design your decal using vector graphics for scalability. Ensure the design is simple and clean.
3. Save the file as a `.png` or `.jpg` for printing.

**Expected Command Output:**
- A new file with the correct dimensions.
- A saved image file of your decal design.

### Step 2: Preparing the Decal for Printing
1. Convert your design to a format suitable for printing on vinyl or paper. This may involve adjusting the color mode and resolution.
2. Print the decal on the appropriate material.

**Expected Command Output:**
- A printed decal on vinyl or paper.

### Step 3: Cutting the Decal
1. If using a vinyl cutter, import the design file and cut the decal.
2. If using scissors, carefully cut the decal along the design lines.

**Expected Command Output:**
- A cut decal ready for application.

## Exercise 2: Building, Configuring & Deploying a Production Scenario

### Step 1: Applying the Decal
1. Clean the surface of the LEGO piece where the decal will be applied.
2. Apply adhesive spray to the LEGO piece or use transfer tape.
3. Carefully align the decal with the LEGO piece and press it into place.
4. Smooth out any air bubbles and allow the decal to dry.

**Expected Command Output:**
- A LEGO piece with the decal properly applied.

### Step 2: Inspecting the Decal
1. Inspect the decal for any air bubbles, wrinkles, or misalignment.
2. Make adjustments if necessary.

**Expected Command Output:**
- A properly applied decal with no visible issues.

## Exercise 3: Fault Injection, Failure Analysis & Debugging

### Fault Injection: Misaligned Decal
1. Intentionally misalign the decal during application.
2. Observe the result and identify the issue.

**Expected Command Output:**
- A misaligned decal.

### Failure Analysis & Debugging
1. Identify the cause of the misalignment (e.g., incorrect positioning, uneven surface).
2. Correct the issue and reapply the decal.

**Expected Command Output:**
- A properly aligned decal.

## Challenge Lab: Independent Advanced Scenarios

### Scenario 1: Multi-Piece Decal
1. Design a decal that spans multiple LEGO pieces.
2. Print and cut the decal.
3. Apply the decal to the LEGO pieces.

**Expected Command Output:**
- A multi-piece LEGO model with a seamless decal applied.

### Scenario 2: Detailed Design
1. Create a detailed design with intricate patterns or text.
2. Print and cut the decal.
3. Apply the decal to a LEGO piece.

**Expected Command Output:**
- A LEGO piece with a detailed decal applied.

### Scenario 3: Colorful Decals
1. Design a decal using multiple colors.
2. Print and cut the decal.
3. Apply the decal to a LEGO piece.

**Expected Command Output:**
- A LEGO piece with a colorful decal applied.

By completing this lab, you should have a solid understanding of how to create and apply custom decals to LEGO models. Practice these steps to refine your skills and create stunning LEGO creations.
