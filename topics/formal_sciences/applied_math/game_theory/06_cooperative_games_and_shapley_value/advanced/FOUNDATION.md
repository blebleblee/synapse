# Advanced Foundation: Game Theory 06 Cooperative Games And Shapley Value

## 1. Theoretical Invariants & Formal Frameworks (Formal proofs, kernel or physical invariants)

### Cooperative Games
A cooperative game is a game where players can form coalitions to achieve a common goal. The characteristic function $v: 2^N \rightarrow \mathbb{R}$ assigns a real value to every subset of players $S \subseteq N$, representing the total payoff that the coalition $S$ can achieve if it acts together. Here, $N$ is the set of all players.

### Shapley Value
The Shapley value is a solution concept in cooperative game theory that assigns a unique distribution of the total surplus generated by the coalition of all players among the players. It is defined as:
\[
\phi_i(v) = \frac{1}{n!} \sum_{\pi \in \Pi(N)} \left( v(S_i^\pi \cup \{i\}) - v(S_i^\pi) \right)
\]
where $\Pi(N)$ is the set of all permutations of $N$, and $S_i^\pi$ is the set of players preceding player $i$ in permutation $\pi$.

#### Formal Proof of Shapley Value Axioms
The Shapley value satisfies the following axioms:
1. **Efficiency:** $\sum_{i \in N} \phi_i(v) = v(N)$.
2. **Symmetry:** If $v(S \cup \{i\}) = v(S \cup \{j\})$ for all $S \subseteq N \setminus \{i, j\}$, then $\phi_i(v) = \phi_j(v)$.
3. **Dummy Player:** If $v(S \cup \{i\}) = v(S)$ for all $S \subseteq N \setminus \{i\}$, then $\phi_i(v) = 0$.
4. **Additivity:** If $u, w: 2^N \rightarrow \mathbb{R}$, then $\phi_i(u + w) = \phi_i(u) + \phi_i(w)$.

**Proof of Efficiency:**
\[
\sum_{i \in N} \phi_i(v) = \sum_{i \in N} \frac{1}{n!} \sum_{\pi \in \Pi(N)} \left( v(S_i^\pi \cup \{i\}) - v(S_i^\pi) \right) = \frac{1}{n!} \sum_{\pi \in \Pi(N)} \left( v(N) - v(\emptyset) \right) = v(N)
\]

## 2. Low-Level Invariant Taxonomy (Deep registers, memory models, hardware constraints, or axiomatic definitions)

### Axiomatic Definitions
- **Monotonicity:** If $v(S \cup \{i\}) \geq w(S \cup \{i\})$ for all $S \subseteq N \setminus \{i\}$, then $\phi_i(v) \geq \phi_i(w)$.
- **Null Player:** If $v(S \cup \{i\}) = v(S)$ for all $S \subseteq N \setminus \{i\}$, then $\phi_i(v) = 0$.

### Hardware Constraints
In the context of cooperative games, hardware constraints can be modeled as limitations on the computational resources available to evaluate the characteristic function $v(S)$. For example, if evaluating $v(S)$ requires significant computational power, the Shapley value calculation may be infeasible for large coalitions.

### Cache and Race Conditions
In distributed systems, the evaluation of the characteristic function $v(S)$ may be cached to improve performance. However, care must be taken to avoid race conditions when updating the cache. For example, if two players simultaneously join a coalition, the characteristic function may be evaluated twice, leading to inconsistent results.

## 4. Subtle Failure Modes & Boundary Conditions

### Failure Modes
- **Inconsistent Characteristic Function:** If the characteristic function $v(S)$ is not consistent (i.e., $v(S \cup \{i\}) < v(S)$ for some $S \subseteq N \setminus \{i\}$), the Shapley value may not be well-defined.
- **Computational Infeasibility:** For large coalitions, the computation of the Shapley value may be computationally infeasible due to the factorial number of permutations.

### Boundary Conditions
- **Empty Coalition:** The Shapley value for the empty coalition is always zero, i.e., $\phi_i(\emptyset) = 0$.
- **Singleton Coalition:** The Shapley value for a singleton coalition is equal to the characteristic function of that coalition, i.e., $\phi_i(\{i\}) = v(\{i\})$.
