# Lesson 2: Set Theory, Relations, Functions

## 1. First-Principles Intuition & Invariants

Set theory stands as the axiomatic foundation upon which modern mathematics constructs its edifice. When Georg Cantor formalized set-theoretic concepts in the late nineteenth century, he provided mathematicians with a unified language for discussing collections, membership, and cardinality—concepts that had previously existed only in intuitive, informal terms. The transition from naive set theory to axiomatic frameworks like Zermelo-Fraenkel set theory (ZF) arose precisely because unrestricted set formation leads to paradoxes, most famously Russell's paradox concerning the set of all sets that do not contain themselves. For our purposes in discrete mathematics, we adopt a pragmatic middle path: we work within an intuitive framework sufficient for algorithm analysis, combinatorics, and logic, while remaining aware of the axiomatic boundaries that prevent contradiction.

A **set** is an unordered collection of distinct objects called **elements** or **members**. We denote membership with the symbol $\in$, writing $x \in A$ to express that $x$ is an element of set $A$, and $x \notin A$ to express non-membership. The fundamental invariant distinguishing sets from other collection structures—multisets, sequences, or bags—is that order and repetition are irrelevant. The set $\{1, 2, 3\}$ is identical to $\{3, 2, 1\}$ and to $\{1, 1, 2, 3, 3\}$. This extensionality principle states that two sets are equal if and only if they contain precisely the same elements: $A = B \iff \forall x (x \in A \leftrightarrow x \in B)$.

Sets may be specified through explicit enumeration using roster notation, such as $A = \{2, 4, 6, 8\}$, or through set-builder notation, which defines membership by a predicate: $A = \{x \in \mathbb{N} : x \text{ is even and } x \le 8\}$. The empty set, denoted $\emptyset$ or $\{\}$, contains no elements and serves as the identity element for union operations. The universal set $U$ contains all elements under consideration in a given context; its precise definition varies with domain but establishes the boundary for complementation operations.

The algebra of sets provides a rich calculus for combining and manipulating collections. The **union** $A \cup B = \{x : x \in A \lor x \in B\}$ collects all elements appearing in either set. The **intersection** $A \cap B = \{x : x \in A \land x \in B\}$ retains only shared elements. The **difference** $A \setminus B = \{x : x \in A \land x \notin B\}$ removes elements of $B$ from $A$, while the **symmetric difference** $A \triangle B = (A \setminus B) \cup (B \setminus A)$ captures elements belonging to exactly one set. The **complement** $\overline{A} = U \setminus A$ consists of all elements in the universal set not in $A$.

These operations satisfy a constellation of algebraic laws that mirror Boolean algebra and propositional logic. Commutativity holds for union and intersection: $A \cup B = B \cup A$ and $A \cap B = B \cap A$. Associativity permits grouping: $(A \cup B) \cup C = A \cup (B \cup C)$ and $(A \cap B) \cap C = A \cap (B \cap C)$. The distributive laws interlink union and intersection: $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ and dually $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$. De Morgan's laws translate negations across operations: $\overline{A \cup B} = \overline{A} \cap \overline{B}$ and $\overline{A \cap B} = \overline{A} \cup \overline{B}$.

We prove De Morgan's first law to illustrate the extensionality-based proof technique fundamental to set theory. We must show $\overline{A \cup B} = \overline{A} \cap \overline{B}$ by demonstrating mutual subset inclusion. First, suppose $x \in \overline{A \cup B}$. Then $x \notin A \cup B$, which by definition of union means $x \notin A$ and $x \notin B$. Thus $x \in \overline{A}$ and $x \in \overline{B}$, so $x \in \overline{A} \cap \overline{B}$. This establishes $\overline{A \cup B} \subseteq \overline{A} \cap \overline{B}$. Conversely, suppose $x \in \overline{A} \cap \overline{B}$. Then $x \in \overline{A}$ and $x \in \overline{B}$, meaning $x \notin A$ and $x \notin B$. Therefore $x \notin A \cup B$, so $x \in \overline{A \cup B}$. This gives $\overline{A} \cap \overline{B} \subseteq \overline{A \cup B}$. By mutual inclusion, the sets are equal.

The **power set** $\mathcal{P}(A)$ of a set $A$ is the set of all subsets of $A$, including both $\emptyset$ and $A$ itself. If $A$ has cardinality $n$, then $|\mathcal{P}(A)| = 2^n$, a result that follows from the bijection between subsets and binary indicator functions. For $A = \{1, 2, 3\}$, the power set contains eight elements: $\mathcal{P}(A) = \{\emptyset, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}\}$. Each subset corresponds to a three-bit string indicating membership, establishing the exponential relationship between set size and power set cardinality.

The **Cartesian product** $A \times B$ of sets $A$ and $B$ is the set of all ordered pairs $(a, b)$ where $a \in A$ and $b \in B$. Unlike sets themselves, ordered pairs preserve position: $(a, b) \ne (b, a)$ unless $a = b$. The Cartesian product respects cardinality multiplicatively: $|A \times B| = |A| \cdot |B|$. We may extend this construction to arbitrary finite products: $A_1 \times A_2 \times \cdots \times A_n$ yields $n$-tuples, and the $n$-fold Cartesian product $A^n = A \times A \times \cdots \times A$ produces all $n$-tuples with components from $A$. The real plane $\mathbb{R}^2 = \mathbb{R} \times \mathbb{R}$ and three-dimensional space $\mathbb{R}^3$ are Cartesian products familiar from analytic geometry.

A **relation** from set $A$ to set $B$ is simply a subset $R \subseteq A \times B$. When $(a, b) \in R$, we say that $a$ is related to $b$ and often write $a \mathrel{R} b$ using infix notation. A relation on a single set $A$ is a subset $R \subseteq A \times A$, providing a formal framework for describing pairwise connections within a structure. The **domain** of relation $R$ is $\text{dom}(R) = \{a \in A : \exists b \in B, (a,b) \in R\}$, while the **range** or **image** is $\text{ran}(R) = \{b \in B : \exists a \in A, (a,b) \in R\}$.

Relations on a set $A$ possess structural properties that govern their behavior. A relation $R$ is **reflexive** if every element relates to itself: $\forall a \in A, a \mathrel{R} a$. It is **symmetric** if relatedness works bidirectionally: $\forall a, b \in A, (a \mathrel{R} b \implies b \mathrel{R} a)$. It is **transitive** if relatedness composes: $\forall a, b, c \in A, (a \mathrel{R} b \land b \mathrel{R} c \implies a \mathrel{R} c)$. It is **antisymmetric** if bidirectional relatedness implies equality: $\forall a, b \in A, (a \mathrel{R} b \land b \mathrel{R} a \implies a = b)$. These properties combine to characterize fundamental mathematical structures.

An **equivalence relation** on set $A$ is a relation that is reflexive, symmetric, and transitive. Equivalence relations formalize the notion of "sameness" or "indistinguishability" with respect to some property. The canonical example is congruence modulo $n$ on the integers: $a \equiv b \pmod{n}$ if and only if $n \mid (a - b)$. We verify that congruence modulo $n$ is an equivalence relation. Reflexivity holds because $a - a = 0 = n \cdot 0$, so $n \mid (a - a)$ and $a \equiv a \pmod{n}$. For symmetry, suppose $a \equiv b \pmod{n}$. Then $n \mid (a - b)$, so $a - b = nk$ for some integer $k$. Thus $b - a = n(-k)$, giving $n \mid (b - a)$ and $b \equiv a \pmod{n}$. For transitivity, suppose $a \equiv b \pmod{n}$ and $b \equiv c \pmod{n}$. Then $a - b = nk$ and $b - c = n\ell$ for integers $k$ and $\ell$. Adding these equations yields $a - c = n(k + \ell)$, so $n \mid (a - c)$ and $a \equiv c \pmod{n}$.

Given an equivalence relation $R$ on $A$, the **equivalence class** of element $a$ is $[a] = \{b \in A : a \mathrel{R} b\}$, the set of all elements equivalent to $a$. These equivalence classes partition the set $A$ into disjoint, exhaustive subsets. Two equivalence classes are either identical or disjoint: if $[a] \cap [b] \ne \emptyset$, then $[a] = [b]$. To prove this, suppose $c \in [a] \cap [b]$. Then $a \mathrel{R} c$ and $b \mathrel{R} c$. By symmetry, $c \mathrel{R} b$, and by transitivity with $a \mathrel{R} c$, we obtain $a \mathrel{R} b$. Now take any $x \in [a]$. Then $a \mathrel{R} x$, and by transitivity with $a \mathrel{R} b$, we get $b \mathrel{R} x$, so $x \in [b]$. This shows $[a] \subseteq [b]$. The reverse inclusion follows symmetrically, establishing $[a] = [b]$.

The collection of all equivalence classes forms a **partition** of $A$: a family of non-empty, pairwise disjoint subsets whose union equals $A$. Conversely, every partition of $A$ induces an equivalence relation where $a \mathrel{R} b$ if and only if $a$ and $b$ belong to the same partition block. This bijective correspondence between equivalence relations and partitions provides a powerful conceptual and computational tool. The **quotient set** $A/R$ is the set of all equivalence classes, and the natural projection $\pi : A \to A/R$ defined by $\pi(a) = [a]$ maps each element to its equivalence class.

A **partial order** on set $A$ is a relation that is reflexive, antisymmetric, and transitive. Partial orders formalize hierarchical or precedence structures where not all elements need be comparable. The standard ordering $\le$ on real numbers is a **total order** (or **linear order**), a partial order satisfying the additional comparability property: $\forall a, b \in A, (a \le b \lor b \le a)$. The subset relation $\subseteq$ on $\mathcal{P}(A)$ provides a canonical partial order that is not total: sets $\{1, 2\}$ and $\{2, 3\}$ are incomparable under inclusion.

In a partially ordered set (or **poset**) $(A, \le)$, an element $a$ is **minimal** if no element is strictly smaller: there exists no $b \in A$ with $b < a$ (where $b < a$ means $b \le a$ and $b \ne a$). It is a **minimum** or **least element** if it is smaller than or equal to every element: $\forall b \in A, a \le b$. Dually, $a$ is **maximal** if no element is strictly larger, and a **maximum** or **greatest element** if $\forall b \in A, b \le a$. A poset may have multiple minimal or maximal elements but at most one minimum and one maximum. The divisibility relation on positive integers has minimum $1$ (which divides all integers) but no maximum; the subset relation on $\mathcal{P}(\{1,2\})$ has minimum $\emptyset$ and maximum $\{1, 2\}$.

Given a subset $B \subseteq A$ in poset $(A, \le)$, an **upper bound** for $B$ is an element $u \in A$ such that $\forall b \in B, b \le u$. The **least upper bound** or **supremum** $\sup B$ is an upper bound that is less than or equal to every upper bound. Dually, a **lower bound** is an element $\ell \in A$ with $\forall b \in B, \ell \le b$, and the **greatest lower bound** or **infimum** $\inf B$ is a lower bound exceeding all lower bounds. These concepts generalize maximum and minimum: $\max B$ is the supremum when it exists and belongs to $B$, while $\sup B$ may exist even when $B$ has no maximum. In the real numbers with standard ordering, the set $(0, 1)$ has no maximum but $\sup(0, 1) = 1$.

A **lattice** is a poset in which every pair of elements has both a least upper bound (called the **join** $a \lor b$) and a greatest lower bound (called the **meet** $a \land b$). Lattices provide algebraic structure to ordering relations, enabling computations with suprema and infima. The power set $\mathcal{P}(A)$ under $\subseteq$ forms a lattice with join given by union and meet by intersection: $X \lor Y = X \cup Y$ and $X \land Y = X \cap Y$. The divisibility poset on positive integers forms a lattice with join given by least common multiple and meet by greatest common divisor: $a \lor b = \text{lcm}(a, b)$ and $a \land b = \gcd(a, b)$.

## 2. Core Architecture & Mechanics

A **function** $f : A \to B$ from set $A$ to set $B$ is a special relation satisfying a uniqueness constraint: for every $a \in A$, there exists exactly one $b \in B$ such that $(a, b) \in f$. We denote this unique $b$ by $f(a)$, the **image** or **value** of $a$ under $f$. The set $A$ is the **domain** of $f$, while $B$ is the **codomain**. The **range** or **image** of $f$ is $\text{im}(f) = \{f(a) : a \in A\} = \{b \in B : \exists a \in A, f(a) = b\}$. Note that the range is a subset of the codomain that may be proper: not every element of $B$ need be achieved as an output.

The defining property of functions—that each input determines exactly one output—distinguishes them from arbitrary relations. The relation $R = \{(1, 2), (1, 3), (2, 4)\} \subseteq \{1, 2\} \times \{2, 3, 4\}$ is not a function because $1$ maps to both $2$ and $3$. The relation $R = \{(1, 2), (2, 4)\} \subseteq \{1, 2, 3\} \times \{2, 4\}$ is not a function from $\{1, 2, 3\}$ because $3$ has no image. However, it is a **partial function** on $\{1, 2, 3\}$, a relaxation permitting undefined values for some domain elements. In discrete mathematics and computer science, we typically work with total functions where every input has a defined output.

Functions may be specified through explicit formulas like $f(x) = x^2 + 3x - 5$, through algorithmic procedures, through tables enumerating input-output pairs, or through case-based definitions. The **identity function** $\text{id}_A : A \to A$ defined by $\text{id}_A(a) = a$ maps every element to itself. **Constant functions** $f : A \to B$ map all elements of $A$ to a single fixed element $b_0 \in B$: $f(a) = b_0$ for all $a \in A$.

A function $f : A \to B$ is **injective** (or **one-to-one**) if distinct inputs yield distinct outputs: $\forall a_1, a_2 \in A, (f(a_1) = f(a_2) \implies a_1 = a_2)$. Equivalently, $f$ is injective if $a_1 \ne a_2$ implies $f(a_1) \ne f(a_2)$. Injectivity ensures that $f$ encodes information without collisions; no two domain elements compete for the same codomain element. The function $f : \mathbb{R} \to \mathbb{R}$ given by $f(x) = 2x + 3$ is injective. To verify this, suppose $f(x_1) = f(x_2)$. Then $2x_1 + 3 = 2x_2 + 3$, so $2x_1 = 2x_2$, giving $x_1 = x_2$. The function $g : \mathbb{R} \to \mathbb{R}$ defined by $g(x) = x^2$ is not injective because $g(-2) = g(2) = 4$ but $-2 \ne 2$.

A function $f : A \to B$ is **surjective** (or **onto**) if every codomain element is the image of some domain element: $\forall b \in B, \exists a \in A, f(a) = b$. Equivalently, $f$ is surjective if $\text{im}(f) = B$. Surjectivity ensures that $f$ covers the entire codomain with no "wasted" elements. The function $h : \mathbb{R} \to \mathbb{R}$ given by $h(x) = x^3$ is surjective because for any $y \in \mathbb{R}$, we can solve $x^3 = y$ to obtain $x = \sqrt[3]{y} \in \mathbb{R}$, so $h(\sqrt[3]{y}) = y$. The function $k : \mathbb{R} \to \mathbb{R}$ defined by $k(x) = e^x$ is not surjective because $e^x > 0$ for all $x$, so negative numbers have no preimages.

A function $f : A \to B$ is **bijective** (or a **one-to-one correspondence**) if it is both injective and surjective. Bijections establish a perfect pairing between domain and codomain, with each domain element matching exactly one codomain element and vice versa. The existence of a bijection $f : A \to B$ means that $A$ and $B$ have the same cardinality, denoted $|A| = |B|$, even for infinite sets. The function $f : \mathbb{R} \to \mathbb{R}$ given by $f(x) = 2x + 3$ is bijective: we have already shown injectivity, and for surjectivity, given any $y \in \mathbb{R}$, we solve $2x + 3 = y$ to obtain $x = (y - 3)/2$, so $f((y-3)/2) = y$.

Given functions $f : A \to B$ and $g : B \to C$, the **composition** $g \circ f : A \to C$ is defined by $(g \circ f)(a) = g(f(a))$. Composition applies $f$ first, then applies $g$ to the result. This operation is associative: $(h \circ g) \circ f = h \circ (g \circ f)$ whenever the domains and codomains align, but it is generally not commutative: $g \circ f \ne f \circ g$ even when both are defined. The identity function serves as a composition identity: $f \circ \text{id}_A = f$ and $\text{id}_B \circ f = f$ for $f : A \to B$.

Composition preserves injectivity and surjectivity in a precise sense. If $f : A \to B$ and $g : B \to C$ are both injective, then $g \circ f : A \to C$ is injective. To prove this, suppose $(g \circ f)(a_1) = (g \circ f)(a_2)$. Then $g(f(a_1)) = g(f(a_2))$. Since $g$ is injective, $f(a_1) = f(a_2)$. Since $f$ is injective, $a_1 = a_2$. Therefore $g \circ f$ is injective. Similarly, if $f$ and $g$ are both surjective, then $g \circ f$ is surjective. To prove this, take any $c \in C$. Since $g$ is surjective, there exists $b \in B$ with $g(b) = c$. Since $f$ is surjective, there exists $a \in A$ with $f(a) = b$. Then $(g \circ f)(a) = g(f(a)) = g(b) = c$, showing that $g \circ f$ is surjective. Combining these results, if $f$ and $g$ are bijective, then $g \circ f$ is bijective.

A function $f : A \to B$ has an **inverse function** $f^{-1} : B \to A$ if there exists a function satisfying $f^{-1} \circ f = \text{id}_A$ and $f \circ f^{-1} = \text{id}_B$. These conditions state that $f^{-1}(f(a)) = a$ for all $a \in A$ and $f(f^{-1}(b)) = b$ for all $b \in B$. A function has an inverse if and only if it is bijective. The "only if" direction follows from the defining equations: if $f$ has an inverse, then $f$ is injective because $f(a_1) = f(a_2)$ implies $a_1 = f^{-1}(f(a_1)) = f^{-1}(f(a_2)) = a_2$, and $f$ is surjective because for any $b \in B$, setting $a = f^{-1}(b)$ gives $f(a) = f(f^{-1}(b)) = b$.

For the "if" direction, suppose $f : A \to B$ is bijective. We construct $f^{-1} : B \to A$ as follows: for each $b \in B$, surjectivity guarantees the existence of some $a \in A$ with $f(a) = b$, and injectivity guarantees uniqueness of this $a$. Define $f^{-1}(b)$ to be this unique $a$. Then $f^{-1}(f(a)) = a$ by construction, and $f(f^{-1}(b)) = b$ because $f^{-1}(b)$ was chosen to satisfy $f(f^{-1}(b)) = b$. Thus $f^{-1}$ is the inverse of $f$. When an inverse exists, it is unique: if $g_1$ and $g_2$ are both inverses of $f$, then $g_1 = g_1 \circ \text{id}_B = g_1 \circ (f \circ g_2) = (g_1 \circ f) \circ g_2 = \text{id}_A \circ g_2 = g_2$.

The inverse of a bijection is itself bijective, and $(f^{-1})^{-1} = f$. For compositions, the inverse of $g \circ f$ is $f^{-1} \circ g^{-1}$ (note the order reversal): $(g \circ f) \circ (f^{-1} \circ g^{-1}) = g \circ (f \circ f^{-1}) \circ g^{-1} = g \circ \text{id}_B \circ g^{-1} = g \circ g^{-1} = \text{id}_C$, and similarly $(f^{-1} \circ g^{-1}) \circ (g \circ f) = \text{id}_A$.

For finite sets, injectivity, surjectivity, and bijectivity interrelate through cardinality constraints. If $f : A \to B$ is injective, then $|A| \le |B|$ because distinct elements of $A$ map to distinct elements of $B$. If $f$ is surjective, then $|A| \ge |B|$ because every element of $B$ requires at least one preimage in $A$. When $|A| = |B|$ and $f : A \to B$ is a function between finite sets, injectivity implies surjectivity and vice versa, so $f$ is bijective. This equivalence breaks down for infinite sets: the function $f : \mathbb{N} \to \mathbb{N}$ given by $f(n) = 2n$ is injective but not surjective.

The **restriction** of function $f : A \to B$ to subset $S \subseteq A$ is the function $f|_S : S \to B$ defined by $f|_S(s) = f(s)$ for all $s \in S$. Restriction narrows the domain while preserving the functional relationship. The **image** of subset $S \subseteq A$ under $f$ is $f(S) = \{f(s) : s \in S\} = \{b \in B : \exists s \in S, f(s) = b\}$. The **preimage** or **inverse image** of subset $T \subseteq B$ under $f$ is $f^{-1}(T) = \{a \in A : f(a) \in T\}$. Note that $f^{-1}(T)$ is well-defined even when $f$ has no inverse function; the notation overloads $f^{-1}$ to denote both inverse functions (when they exist) and preimage sets (which always exist).

Preimages preserve set operations in a particularly clean way. For any subsets $T_1, T_2 \subseteq B$, we have $f^{-1}(T_1 \cup T_2) = f^{-1}(T_1) \cup f^{-1}(T_2)$, $f^{-1}(T_1 \cap T_2) = f^{-1}(T_1) \cap f^{-1}(T_2)$, and $f^{-1}(B \setminus T_1) = A \setminus f^{-1}(T_1)$. We prove the union identity. Take $a \in f^{-1}(T_1 \cup T_2)$. Then $f(a) \in T_1 \cup T_2$, so $f(a) \in T_1$ or $f(a) \in T_2$. If $f(a) \in T_1$, then $a \in f^{-1}(T_1) \subseteq f^{-1}(T_1) \cup f^{-1}(T_2)$. If $f(a) \in T_2$, then $a \in f^{-1}(T_2) \subseteq f^{-1}(T_1) \cup f^{-1}(T_2)$. Thus $f^{-1}(T_1 \cup T_2) \subseteq f^{-1}(T_1) \cup f^{-1}(T_2)$. Conversely, suppose $a \in f^{-1}(T_1) \cup f^{-1}(T_2)$. Then $a \in f^{-1}(T_1)$ or $a \in f^{-1}(T_2)$, so $f(a) \in T_1$ or $f(a) \in T_2$, giving $f(a) \in T_1 \cup T_2$ and $a \in f^{-1}(T_1 \cup T_2)$. This establishes $f^{-1}(T_1) \cup f^{-1}(T_2) \subseteq f^{-1}(T_1 \cup T_2)$, completing the proof.

Images interact with set operations less symmetrically. We have $f(S_1 \cup S_2) = f(S_1) \cup f(S_2)$ for any subsets $S_1, S_2 \subseteq A$. However, $f(S_1 \cap S_2) \subseteq f(S_1) \cap f(S_2)$ holds in general, but equality fails for non-injective functions. For example, let $f : \{1, 2\} \to \{3\}$ be the constant function $f(1) = f(2) = 3$. Then $f(\{1\}) \cap f(\{2\}) = \{3\} \cap \{3\} = \{3\}$, but $f(\{1\} \cap \{2\}) = f(\emptyset) = \emptyset$. The inclusion becomes an equality precisely when $f$ is injective.

**Characteristic functions** provide a bijective correspondence between subsets of $A$ and functions from $A$ to $\{0, 1\}$. Given subset $S \subseteq A$, the characteristic function $\chi_S : A \to \{0, 1\}$ is defined by $\chi_S(a) = 1$ if $a \in S$ and $\chi_S(a) = 0$ if $a \notin S$. This encoding converts subset operations into pointwise arithmetic: $\chi_{S \cup T} = \max(\chi_S, \chi_T)$, $\chi_{S \cap T} = \chi_S \cdot \chi_T$, and $\chi_{\overline{S}} = 1 - \chi_S$. The number of functions from $A$ to $\{0, 1\}$ is $2^{|A|}$, which explains the power set cardinality formula.

Consider the problem of counting functions between finite sets. The number of functions from set $A$ with $m$ elements to set $B$ with $n$ elements is $n^m$, because each of the $m$ domain elements independently chooses one of $n$ codomain values. The number of injective functions from $A$ to $B$ when $m \le n$ is $n(n-1)(n-2) \cdots (n-m+1) = \frac{n!}{(n-m)!}$, the falling factorial or $m$-permutation of $n$. The first domain element has $n$ choices, the second has $n-1$ remaining choices (to ensure distinctness), the third has $n-2$, and so on. When $m = n$, the number of bijections equals $n!$, the number of permutations of $n$ elements.

The **floor function** $\lfloor x \rfloor$ maps real number $x$ to the greatest integer less than or equal to $x$, while the **ceiling function** $\lceil x \rceil$ maps $x$ to the least integer greater than or equal to $x$. These functions bridge continuous and discrete domains, essential for algorithm analysis. For positive integers $m$ and $n$, the quotient $\lfloor m/n \rfloor$ gives the result of integer division, and $m - n\lfloor m/n \rfloor$ gives the remainder. Modular arithmetic defines $a \bmod n = a - n\lfloor a/n \rfloor$, the unique integer $r$ with $0 \le r < n$ and $a = qn + r$ for some integer $q$.

Functions on finite sets may be visualized through directed graphs where vertices represent elements and edges represent the function relation. For $f : A \to A$, each vertex has out-degree $1$ (exactly one outgoing edge), and the graph decomposes into trees directed toward cycles. Iterating the function generates trajectories: starting from $a_0$, we compute $a_1 = f(a_0)$, $a_2 = f(a_1)$, and so on. For finite $A$, trajectories eventually enter cycles, and the **eventual period** of $a_0$ is the cycle length once periodicity begins. Understanding function iteration underpins pseudorandom number generation, hash functions, and computational complexity analysis.

## 3. High-Performance Optimization & Failure Modes

In computational practice, set operations require efficient data structures balancing space consumption against operation time complexity. Hash tables provide average-case $O(1)$ membership testing, insertion, and deletion, making them ideal for dynamic sets with frequent updates. The hash function maps elements to bucket indices, and collision resolution strategies—chaining with linked lists or open addressing with probing sequences—handle elements hashing to the same location. A well-designed hash function distributes elements uniformly across buckets, keeping collision chains short and operations fast. Load factor $\alpha = n/m$, where $n$ is the number of stored elements and $m$ is the table size, governs performance: when $\alpha$ exceeds a threshold (typically $0.7$ to $0.75$), rehashing to a larger table maintains efficiency.

Bit vectors represent subsets of $\{0, 1, \ldots, n-1\}$ using $n$ bits, where bit $i$ indicates membership of element $i$. This encoding supports union, intersection, and complement through bitwise OR, AND, and NOT operations executable in parallel on word-sized chunks. For universe size $n = 64$, a single 64-bit integer represents the entire set, and operations complete in constant time. For larger universes, bit vectors consume $\lceil n/8 \rceil$ bytes but enable cache-efficient batch processing. Sparse sets where $|S| \ll n$ waste space with bit vectors; sorted arrays or balanced search trees may be preferable.

Self-balancing binary search trees like AVL trees or red-black trees maintain sets of comparable elements with $O(\log n)$ operations. These structures preserve sorted order, enabling efficient range queries and order statistics (finding the $k$-th smallest element). Tree rotations preserve the binary search tree invariant while rebalancing after insertions and deletions. Red-black trees relax balance constraints compared to AVL trees, reducing rotation overhead during updates at the cost of slightly deeper trees.

Disjoint-set data structures (union-find) efficiently maintain partitions induced by equivalence relations. The structure supports two primary operations: `find(x)` returns the representative of the equivalence class containing $x$, and `union(x, y)` merges the classes containing $x$ and $y$. Path compression during `find` operations and union by rank or size ensure that a sequence of $m$ operations on $n$ elements runs in $O(m \alpha(n))$ time, where $\alpha$ is the extremely slow-growing inverse Ackermann function, effectively constant for practical $n$. This near-linear performance makes union-find indispensable for Kruskal's minimum spanning tree algorithm, image segmentation, and maintaining connectivity in dynamic graphs.

When working with Cartesian products computationally, explicit enumeration grows exponentially with dimension. For $A^n$ where $|A| = k$, the product contains $k^n$ elements. Iterating through all elements requires nested loops or recursive generation, feasible for small $n$ but intractable for large $n$. Gray codes provide a sequence visiting all $n$-bit strings such that consecutive entries differ in exactly one bit, minimizing transition cost in physical or logical systems. The standard binary-reflected Gray code is defined recursively: the one-bit Gray code is $(0, 1)$, and the $(n+1)$-bit code concatenates $0$ prepended to the $n$-bit code with $1$ prepended to the reverse of the $n$-bit code.

Function composition requires compatible domains and codomains, a constraint easily violated in complex systems. Type systems in programming languages enforce these compatibility requirements at compile time, preventing composition errors. In mathematical analysis, tracking domain restrictions becomes critical: composing $f(x) = 1/x$ with $g(x) = x - 1$ yields $(f \circ g)(x) = 1/(x-1)$, valid only when $x \ne 1$. The domain of the composition is the preimage under the inner function of the domain of the outer function: $\text{dom}(f \circ g) = g^{-1}(\text{dom}(f)) \cap \text{dom}(g)$.

Verifying injectivity computationally is straightforward when the domain is finite: iterate through all pairs and check for collisions. For infinite or large finite domains defined by formulas, algebraic techniques apply. To prove $f : \mathbb{Z} \to \mathbb{Z}$ given by $f(x) = 3x + 7$ is injective, assume $f(x_1) = f(x_2)$. Then $3x_1 + 7 = 3x_2 + 7$, so $3x_1 = 3x_2$, giving $x_1 = x_2$. To prove $g : \mathbb{R} \to \mathbb{R}$ given by $g(x) = x^2 - 4x + 5$ is not injective, find distinct $x_1$ and $x_2$ with $g(x_1) = g(x_2)$. Completing the square, $g(x) = (x - 2)^2 + 1$, so $g(1) = (1-2)^2 + 1 = 2$ and $g(3) = (3-2)^2 + 1 = 2$, yet $1 \ne 3$.

Verifying surjectivity requires demonstrating that every codomain element has a preimage. For $h : \mathbb{R} \to \mathbb{R}$ given by $h(x) = 2x - 5$, take arbitrary $y \in \mathbb{R}$ and solve $2x - 5 = y$ to obtain $x = (y + 5)/2 \in \mathbb{R}$. Then $h((y+5)/2) = 2 \cdot (y+5)/2 - 5 = y$, establishing surjectivity. For $k : \mathbb{R} \to \mathbb{R}$ given by $k(x) = x^2 + 1$, note that $k(x) \ge 1$ for all $x$, so $0 \in \mathbb{R}$ has no preimage and $k$ is not surjective. Restricting the codomain to $[1, \infty)$ makes $k$ surjective: for any $y \ge 1$, setting $x = \sqrt{y - 1}$ gives $k(x) = y$.

Computing inverse functions involves solving the equation $y = f(x)$ for $x$ in terms of $y$, then swapping variable names. For $f(x) = (3x + 7)/(2x - 5)$ with domain $\mathbb{R} \setminus \{5/2\}$, we solve $y = (3x + 7)/(2x - 5)$. Multiplying both sides by $2x - 5$ gives $y(2x - 5) = 3x + 7$, so $2xy - 5y = 3x + 7$. Collecting $x$ terms yields $2xy - 3x = 5y + 7$, so $x(2y - 3) = 5y + 7$, giving $x = (5y + 7)/(2y - 3)$. Thus $f^{-1}(y) = (5y + 7)/(2y - 3)$ with domain $\mathbb{R} \setminus \{3/2\}$. We verify: $f(f^{-1}(y)) = f\left(\frac{5y+7}{2y-3}\right) = \frac{3 \cdot \frac{5y+7}{2y-3} + 7}{2 \cdot \frac{5y+7}{2y-3} - 5} = \frac{3(5y+7) + 7(2y-3)}{2(5y+7) - 5(2y-3)} = \frac{15y + 21 + 14y - 21}{10y + 14 - 10y + 15} = \frac{29y}{29} = y$.

Numerical computation of function inverses when closed forms are unavailable employs iterative root-finding methods like Newton-Raphson iteration. To find $x$ satisfying $f(x) = y$, we solve $f(x) - y = 0$ using the iteration $x_{n+1} = x_n - (f(x_n) - y)/f'(x_n)$, which converges quadratically to the root under appropriate conditions. For multivalued inverses like the square root, conventions select a principal branch (the non-negative root for real square roots).

Equivalence relations partition data into equivalence classes, and efficient algorithms must navigate this structure. When processing equivalence classes explicitly, assign a canonical representative to each class (often the lexicographically smallest element) to enable consistent identification. In graph coloring problems, vertices receive colors such that adjacent vertices differ in color; the relation "vertices $u$ and $v$ have the same color" partitions the vertex set. Computing this partition optimally (minimizing the number of colors) is NP-hard for general graphs but polynomial for special classes like bipartite graphs (two colors suffice) or planar graphs (four colors suffice by the Four Color Theorem).

Partial orders arise naturally in dependency resolution, task scheduling, and version control. A **topological sort** of a finite poset produces a linear ordering consistent with the partial order: if $a \le b$ in the poset, then $a$ precedes $b$ in the linear ordering. Directed acyclic graphs (DAGs) represent finite posets with edges pointing from smaller to larger elements. Kahn's algorithm computes a topological sort by repeatedly removing vertices with no incoming edges, processing $O(V + E)$ time for $V$ vertices and $E$ edges. Depth-first search also yields topological orderings through reverse post-order traversal.

The concept of a **closure** formalizes extending a relation to satisfy desired properties. The **reflexive closure** of relation $R$ on $A$ is $R \cup \{(a, a) : a \in A\}$, the smallest reflexive relation containing $R$. The **symmetric closure** is $R \cup \{(b, a) : (a, b) \in R\}$. The **transitive closure** $R^+$ is the smallest transitive relation containing $R$, computed iteratively by adding $(a, c)$ whenever $(a, b) \in R$ and $(b, c) \in R$ until no new pairs emerge. The transitive closure of a directed graph's edge relation captures reachability: $(u, v) \in R^+$ if and only if a path exists from $u$ to $v$. The Floyd-Warshall algorithm computes transitive closure in $O(V^3)$ time by dynamic programming over intermediate vertices.

Detecting cycles in relations on finite sets prevents infinite loops in iterative computations. A relation is **acyclic** if its transitive closure contains no reflexive pairs $(a, a)$ other than those explicitly in the relation. Depth-first search detects cycles by marking vertices as unvisited, visiting, or visited; encountering a visiting vertex during exploration signals a cycle. Strongly connected components, computed via Tarjan's or Kosaraju's algorithm in $O(V + E)$ time, partition a directed graph into maximal regions where every pair of vertices reaches each other, collapsing cycles into single nodes.

Relations and functions underpin relational databases where tables represent relations (sets of tuples) and queries construct new relations through projection (selecting columns), selection (filtering rows), joins (Cartesian product followed by filtering on common attributes), and set operations. SQL's `SELECT`, `FROM`, `WHERE`, and `JOIN` clauses directly instantiate these operations. Functional dependencies $X \to Y$ state that tuples agreeing on attributes $X$ must agree on attributes $Y$, constraining valid table states and guiding normalization to eliminate redundancy.

In algorithm design, bijections between problem instances enable reduction-based complexity analysis. Demonstrating a polynomial-time bijection from problem $P$ to problem $Q$ shows that $P$ and $Q$ have equivalent computational complexity up to polynomial factors. The existence of a bijection $f : A \to B$ proves $|A| = |B|$, a technique essential in combinatorics for counting arguments. For example, the number of binary strings of length $n$ equals $2^n$, proven by the bijection mapping each string to its corresponding subset of $\{1, 2, \ldots, n\}$ via characteristic functions.

Fixed points—elements $x$ satisfying $f(x) = x$—play central roles in iterative algorithms, denotational semantics, and numerical analysis. The Banach Fixed-Point Theorem guarantees that contraction mappings on complete metric spaces possess unique fixed points attainable by iteration, providing convergence guarantees for iterative solvers. Tarski's Fixed-Point Theorem states that monotone functions on complete lattices have fixed points, foundational for logic programming and dataflow analysis.

Function spaces themselves form sets, enabling higher-order reasoning. The set of all functions from $A$ to $B$ is denoted $B^A$ (suggesting exponentiation: $|B^A| = |B|^{|A|}$ for finite sets). **Functionals** are functions whose domain or codomain is a function space, central to calculus of variations and functional analysis. In programming languages, higher-order functions accept functions as arguments or return functions as results, enabling powerful abstraction and composition patterns.

The combinatorial explosion inherent in enumeration problems—power sets, Cartesian products, function spaces—demands strategic algorithmic approaches. Lazy evaluation defers computation until results are needed, avoiding exhaustive generation. Backtracking explores solution spaces systematically while pruning branches violating constraints. Dynamic programming caches subproblem solutions to avoid redundant computation in overlapping recursive structures. These techniques transform intractable exhaustive searches into feasible computations by exploiting problem structure.

Set-theoretic reasoning pervades formal verification where program correctness reduces to proving inclusions between state spaces: the reachable states are a subset of the safe states. Model checking exhaustively explores finite state spaces, verifying temporal logic properties. Abstract interpretation overapproximates program behavior using lattice-theoretic domains, trading precision for decidability. These methods rest on the set-theoretic foundations established in this lesson, translating code into mathematical objects amenable to rigorous analysis.
