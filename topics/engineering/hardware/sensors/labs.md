# Operational Verification Labs: Sensors

## Objective & Operational Lab Setup

Modern sensor systems form the sensory nervous system of embedded platforms, industrial control loops, autonomous vehicles, and Internet-of-Things deployments. This operational verification lab sequence develops practitioner competency in sensor interfacing, signal conditioning, calibration protocol execution, and failure mode diagnosis across resistive, capacitive, thermal, optical, and inertial transducer families. Unlike abstract datasheet comprehension exercises, these labs demand hands-on benchtop execution: you will physically wire sensor interface circuits, capture analog waveforms on oscilloscopes, implement digital filtering algorithms in embedded C, execute multi-point calibration routines with traceable reference standards, and diagnose common failure signatures including drift, hysteresis, cross-axis coupling, and electromagnetic interference susceptibility.

The operational philosophy underlying these exercises prioritizes closed-loop verification over theoretical modeling. Each lab begins with a physical sensor element, progresses through analog signal conditioning and analog-to-digital conversion, implements digital compensation algorithms, and concludes with empirical performance validation against known input stimuli. This methodology mirrors industrial sensor qualification workflows where specification compliance must be demonstrated through repeatable measurement rather than assumed from vendor datasheets. You will develop intuition for the physical mechanisms that limit sensor performance—thermal noise floors, mechanical resonance modes, photodiode dark current, MEMS package stress coupling—and learn to distinguish intrinsic transducer limitations from recoverable interface circuit defects.

The laboratory environment requires a mixed-signal workbench combining analog electronics tools with microcontroller development infrastructure. Your bench must provide a dual-channel oscilloscope with at least 100 MHz bandwidth and 1 GSa/s sample rate for capturing sensor output waveforms and interface bus signals, a benchtop digital multimeter with 6.5-digit resolution for DC accuracy verification, and a precision DC power supply with independent voltage and current limit controls. For thermal sensor characterization, you need a temperature-controlled chamber or hot plate with ±0.5°C stability and a calibrated reference thermometer traceable to NIST standards. Inertial sensor labs require a rate table or manual rotation fixture with angular position readout, while optical sensor exercises demand a calibrated light source with known irradiance and spectral content.

The microcontroller development platform serves as the sensor interface and data acquisition engine. A 32-bit ARM Cortex-M4 or M7 microcontroller development board provides the necessary peripheral set: a 12-bit or higher successive-approximation-register (SAR) analog-to-digital converter with at least 1 MSPS throughput, hardware SPI and I2C controllers for digital sensor communication, general-purpose timer modules for pulse-width measurement, and sufficient SRAM for real-time filtering buffer allocation. The firmware development toolchain must include a bare-metal C compiler with optimization controls, a JTAG or SWD debug probe for breakpoint-based execution control, and a serial terminal interface for printing calibration coefficients and diagnostic telemetry. Avoid Arduino abstraction layers; direct peripheral register access reveals the timing constraints and resource allocation tradeoffs that determine sensor interface robustness.

Signal conditioning circuits occupy the analog interface between raw sensor elements and microcontroller ADC inputs. Your component inventory must include precision instrumentation amplifiers for differential voltage sensing, low-noise operational amplifiers with rail-to-rail input/output ranges for single-supply signal scaling, passive and active filter networks for anti-aliasing and noise rejection, and voltage reference ICs to establish stable ADC full-scale ranges independent of supply rail variation. Resistive sensor interfacing requires decade resistance boxes or precision wirewound resistors for Wheatstone bridge completion and gain setting networks, while capacitive sensors demand low-leakage capacitors and charge amplifier topologies. Every analog stage must include provision for oscilloscope probe points with low-capacitance clips to avoid loading effects during waveform capture.

Calibration reference standards anchor the empirical verification methodology that distinguishes these labs from simulation-only coursework. For temperature sensors, a triple-point-of-water cell or a secondary standard platinum resistance thermometer (SPRT) traceable to ITS-90 provides absolute accuracy; for practical benchtop work, a commercially calibrated digital thermometer with ±0.1°C uncertainty suffices if accompanied by a calibration certificate documenting the traceability chain. Pressure sensor calibration requires a deadweight tester or a digital pressure standard with resolution finer than the sensor under test. Optical sensor calibration demands a radiometrically characterized light source or a transfer-standard photodiode with known spectral responsivity. Inertial sensor calibration leverages precision rate tables for gyroscopes and tilt platforms with angular position encoders for accelerometers. When primary standards exceed budget constraints, cross-calibration against multiple commercial-grade reference instruments with overlapping uncertainty ranges provides sufficient validation for educational and prototype development purposes.

Data acquisition and analysis workflows integrate embedded firmware with host-side post-processing tools. The microcontroller firmware continuously samples sensor outputs, applies real-time digital filtering, timestamps each measurement, and streams formatted data packets over a USB virtual COM port or UART interface to the host PC. A Python-based data acquisition script captures these serial data streams, parses the timestamp and sensor value fields, and writes time-series records to CSV files for archival. Post-processing analysis scripts written in Python with NumPy and Matplotlib libraries compute statistical metrics including mean, standard deviation, Allan variance for noise characterization, and least-squares polynomial fits for calibration curve generation. This host-side analysis separation permits computationally expensive algorithms—FFT spectral analysis, Kalman filter parameter optimization, temperature compensation polynomial fitting—that exceed microcontroller real-time execution constraints while preserving the raw data record for reproducible analysis iterations.

Electromagnetic compatibility considerations pervade practical sensor deployments. Bench power supplies must provide low-noise linear regulators or well-filtered switching regulators to prevent supply rail ripple from coupling into sensor analog front-ends through common-impedance paths. Ground plane layout discipline demands star-grounding topologies where analog sensor grounds, digital microcontroller grounds, and chassis safety grounds connect at a single low-impedance point to avoid circulating ground loop currents. Shielded twisted-pair cabling protects sensor signal leads from radiated electromagnetic interference, with cable shields grounded at the signal conditioning end only to prevent ground loop formation. For high-impedance sensor interfaces—piezoelectric accelerometers, pH electrodes, photodiode transimpedance amplifiers—coaxial cabling with grounded outer conductors provides superior common-mode noise rejection compared to unshielded hookup wire.

Firmware architecture patterns for sensor data acquisition balance real-time determinism with computational efficiency. A hardware timer peripheral triggers ADC conversions at precise sample intervals, eliminating the jitter introduced by software polling loops. Each ADC completion generates an interrupt service routine (ISR) that copies the conversion result into a circular buffer and sets a flag for background processing. The main loop monitors this flag and, when set, dequeues samples from the circular buffer, applies digital filtering cascades, executes calibration compensation equations, and formats output packets for serial transmission. This interrupt-driven architecture maintains deterministic sample timing immune to variable-duration processing tasks while avoiding the complexity of real-time operating system scheduler overhead for single-sensor applications.

Digital filtering algorithms directly embedded in microcontroller firmware suppress noise, reject aliasing artifacts, and extract DC or slowly varying signal components from noisy wideband sensor outputs. A simple infinite impulse response (IIR) first-order low-pass filter implemented as a single-pole exponential moving average requires only two multiply-accumulate operations per sample: `y[n] = alpha * x[n] + (1 - alpha) * y[n-1]`, where `alpha` controls the corner frequency and `x[n]` represents the raw ADC sample. For applications demanding sharper rolloff and linear phase response, a finite impulse response (FIR) filter stores the most recent N samples in a circular buffer and computes the output as the dot product of this sample vector with a fixed coefficient vector. FIR coefficient generation via the Parks-McClellan algorithm yields equiripple passband and stopband responses, but microcontroller implementations typically use simpler windowed-sinc designs precomputed in MATLAB or Python and hardcoded as constant arrays in firmware.

Calibration transforms raw sensor outputs into engineering units through multi-point curve fitting informed by measurements against traceable reference standards. A two-point linear calibration requires only offset and gain coefficients, computed by measuring sensor outputs at two known reference stimuli and solving the simultaneous equations `y1 = m * x1 + b` and `y2 = m * x2 + b` for slope `m` and intercept `b`. Nonlinear sensor transfer functions demand polynomial or rational function fits: a quadratic calibration adds a second-order term `y = a2 * x^2 + a1 * x + a0`, requiring three reference points to solve for the coefficient vector. Higher-order polynomials risk overfitting and amplification of noise at extrapolated values beyond the calibration range; piecewise linear interpolation between tabulated reference points often delivers superior practical performance. All calibration coefficients must be stored in microcontroller nonvolatile memory—EEPROM, flash data pages, or battery-backed SRAM—to survive power cycles and permit field recalibration without firmware reflashing.

Temperature compensation algorithms counteract the temperature-dependent drift exhibited by most sensor technologies. Resistive strain gauges exhibit thermal expansion mismatch with the structure under test, piezoresistive pressure sensors show temperature-dependent offset and sensitivity shifts, and MEMS inertial sensors experience package-stress-induced bias variations across operating temperature. A first-order temperature compensation model measures sensor output at multiple temperatures for a fixed input stimulus, fits a linear function `output_compensated = output_raw - (T_current - T_ref) * TC`, where `TC` denotes the temperature coefficient in output units per degree Celsius. More sophisticated implementations employ lookup tables indexed by on-chip temperature sensor readings, storing correction factors determined during factory calibration across the full operating temperature range. The microcontroller firmware reads the temperature sensor, retrieves the appropriate correction coefficient via table interpolation, and applies the correction multiplicatively or additively depending on whether sensitivity or offset dominates the thermal error budget.

Diagnostic telemetry streams embedded within the sensor data protocol enable remote fault detection and performance degradation monitoring. In addition to calibrated sensor values, the firmware packet structure includes raw ADC counts, supply voltage measurements, on-chip temperature readings, sample timestamp counters, and error flags indicating out-of-range inputs or ADC saturation conditions. This diagnostic data permits post-deployment analysis to distinguish sensor element failures—open thermocouples, cracked MEMS die, contaminated optical surfaces—from interface circuit faults such as reference voltage drift, ADC nonlinearity, or digital bus corruption. Persistent logging of diagnostic metrics to onboard flash memory or transmitted via wireless telemetry links supports predictive maintenance strategies where gradual performance degradation triggers preemptive replacement before catastrophic failure disrupts system operation.

With this operational foundation established, the following exercises progress from single-sensor analog interfacing through digital communication protocols to multi-sensor fusion algorithms, building competency in the complete sensor-to-information pipeline that defines modern embedded sensing systems.

## Exercise 1: Foundational Practical Implementation

### Exercise 1A: Resistive Temperature Detector (RTD) Interface with Wheatstone Bridge Signal Conditioning

This foundational exercise develops competency in precision resistive sensor interfacing using a platinum RTD, four-wire measurement techniques to eliminate lead resistance errors, Wheatstone bridge excitation for differential voltage generation, and instrumentation amplifier conditioning for high common-mode rejection. The platinum RTD exhibits a well-characterized positive temperature coefficient of approximately 0.00385 Ω/Ω/°C, yielding a 100 Ω nominal resistance at 0°C that increases predictably with temperature. Unlike thermistors with highly nonlinear resistance-temperature characteristics, the RTD provides near-linear response across industrial temperature ranges, simplifying calibration curve fitting. However, the small absolute resistance change—only 0.385 Ω per degree Celsius for a Pt100 element—demands careful attention to lead resistance contributions, self-heating errors from excessive excitation current, and common-mode voltage rejection in the analog signal conditioning chain.

Begin by constructing the four-wire RTD measurement circuit on a solderless breadboard. The Pt100 RTD element provides four connection terminals: two current-carrying leads that inject the excitation current through the platinum resistor and two voltage-sensing leads that monitor the voltage drop across the resistor without carrying current. This four-wire Kelvin connection topology eliminates the lead resistance error that would otherwise corrupt two-wire measurements where the same leads carry both excitation current and voltage sensing signals. Connect the RTD current leads to the positive and negative terminals of a 1.00 mA constant current source constructed from a precision voltage reference and op-amp-based Howland current pump. The voltage-sensing leads connect to the high-impedance inputs of an instrumentation amplifier with differential input impedance exceeding 1 GΩ and common-mode rejection ratio (CMRR) greater than 100 dB at DC.

The constant current source topology employs a 2.500 V precision voltage reference (such as the ADR4525 or LM4040) driving the non-inverting input of a rail-to-rail precision op-amp (such as the OPA2991 or LT1013). The op-amp output connects through a 2.49 kΩ precision resistor to the RTD current lead, with the bottom of the RTD returned to circuit ground. Negative feedback from the resistor-RTD junction to the op-amp inverting input forces the voltage across the 2.49 kΩ resistor to equal the reference voltage, establishing a current `I = Vref / R = 2.500 V / 2.49 kΩ = 1.004 mA` independent of RTD resistance variation. Limit excitation current to 1 mA maximum to constrain RTD self-heating below 0.1°C in still air; higher currents improve signal-to-noise ratio at the cost of measurement accuracy degradation from internal power dissipation warming the platinum element above ambient temperature.

The instrumentation amplifier stage provides high input impedance, differential amplification, and common-mode rejection essential for extracting the small differential voltage developed across the RTD from the much larger common-mode voltage imposed by the current source topology. Use a three-op-amp instrumentation amplifier IC such as the INA128 or AD8421, configured for a gain of 101 via a single external resistor `RG = 49.4 kΩ` connected between the gain-setting pins. At 0°C with 1 mA excitation, the Pt100 RTD develops 100 mV differential voltage; the 101× gain delivers 10.10 V at the instrumentation amplifier output. As temperature increases to 100°C, RTD resistance rises to approximately 138.5 Ω, generating 138.5 mV input and 13.99 V output—exceeding the typical 5 V ADC input range. Reduce gain to 50× by adjusting `RG` to 1.00 kΩ, yielding a more practical 5.0 V to 6.9 V output swing across the 0°C to 100°C range suitable for ratiometric ADC measurement.

Connect the instrumentation amplifier output to a 12-bit microcontroller ADC input configured for single-ended measurement against the same 2.500 V precision reference that supplies the RTD excitation current source. This ratiometric measurement topology cancels first-order errors from reference voltage drift: if the reference increases by 1%, both the RTD excitation current and the ADC full-scale voltage increase proportionally, leaving the digitized ratio unchanged. Configure the ADC for maximum resolution by setting the programmable gain amplifier (PGA) to unity gain and selecting the internal 2.50 V reference mode. Enable ADC oversampling and decimation to improve effective resolution from 12 bits to 14 bits by accumulating 16 consecutive samples and right-shifting the sum by 2 bits—exploiting the dithering effect of ADC quantization noise and thermal noise at the analog input.

The embedded firmware implements a cyclic acquisition and processing loop triggered by a hardware timer at 10 Hz sample rate. Each timer interrupt initiates an ADC conversion by writing to the ADC start-of-conversion control register. When the conversion completes, the ADC end-of-conversion interrupt service routine reads the 12-bit result from the data register, accumulates it into a 32-bit running sum, and increments a sample counter. After accumulating 16 samples, the main loop right-shifts the sum by 2 bits to obtain the 14-bit oversampled result, converts the ADC counts to voltage via `V_out = (ADC_counts / 16384) * 2.500 V`, inverts the instrumentation amplifier gain to recover the RTD voltage via `V_RTD = V_out / 50`, computes RTD resistance via `R_RTD = V_RTD / I_excitation`, and finally converts resistance to temperature using the Callendar-Van Dusen equation for Pt100 RTDs.

The Callendar-Van Dusen equation provides the industry-standard polynomial relationship between platinum resistance and temperature for temperatures above 0°C: `R(T) = R0 * (1 + A*T + B*T^2)`, where `R0 = 100 Ω` represents the ice-point resistance, `A = 3.9083 × 10^-3 °C^-1`, and `B = -5.775 × 10^-7 °C^-2`. For temperatures below 0°C, an additional cubic term appears, but restricting this exercise to the 0°C to 100°C range permits the simplified quadratic form. Solving for temperature requires inverting the quadratic equation via the quadratic formula: `T = (-A + sqrt(A^2 - 4*B*(1 - R/R0))) / (2*B)`. Implement this equation in firmware using floating-point arithmetic for clarity during initial development, then optimize to fixed-point integer arithmetic for production deployment by scaling all coefficients and intermediate results to integer representations with explicit bit-shift scaling factors.

Calibration of the RTD measurement channel requires establishing traceability to known temperature reference points. For educational benchtop implementation, prepare an ice-water bath by filling a wide-mouth Dewar flask with crushed ice and distilled water, allowing the mixture to equilibrate for 10 minutes to reach the ice point near 0°C. Immerse the RTD element in the ice bath, ensuring the sensing portion sits fully submerged without touching the container walls. Record 100 consecutive firmware temperature readings and compute the mean and standard deviation. The mean provides the zero-point calibration offset: if the firmware reports 0.5°C instead of 0°C, store a correction offset of -0.5°C in nonvolatile memory. The standard deviation quantifies the short-term repeatability or resolution of the measurement channel; expect values below 0.05°C for a properly implemented system with adequate oversampling and filtering.

Next, establish a second calibration point near 100°C by preparing a boiling water bath heated on a laboratory hot plate or immersion heater. Measure the barometric pressure using a laboratory barometer and compute the expected boiling point via the empirical correction `T_boiling = 100°C + 0.03°C * (P_measured - 101.325 kPa)`, where pressure is expressed in kilopascals. Immerse the RTD in the boiling water, again avoiding container wall contact, and record 100 samples. The mean value provides the span calibration coefficient: if the firmware reports 99.0°C when the corrected boiling point is 100.2°C, compute a span multiplier of `100.2 / 99.0 = 1.0121`. Store this multiplier in nonvolatile memory and apply it multiplicatively to all temperature readings after adding the zero-point offset. This two-point linear calibration compensates for combined errors in the current source magnitude, instrumentation amplifier gain resistor tolerance, ADC reference voltage, and RTD nominal resistance.

Validate the calibrated system by establishing an intermediate reference temperature using a precision digital thermometer with NIST-traceable calibration certificate. Position the calibrated thermometer probe and the RTD element in close thermal proximity within a well-stirred temperature-controlled water bath set to 50°C. Allow 15 minutes for thermal equilibration, then record 100 samples from both instruments. Compute the mean difference between the RTD reading and the reference thermometer reading; deviations exceeding ±0.2°C indicate calibration errors, component tolerances, or self-heating effects requiring investigation. Repeat this validation at 25°C and 75°C to verify linearity across the calibrated range; excessive deviation from a straight-line residual pattern suggests higher-order polynomial correction terms may be necessary for your specific RTD element and signal conditioning implementation.

Diagnose common failure modes by deliberately introducing faults and observing the diagnostic telemetry. Disconnect one of the RTD current-carrying leads to simulate an open-circuit fault; the ADC output should rail to its maximum value as the instrumentation amplifier input floats to an undefined voltage. Implement firmware fault detection by comparing the ADC reading against threshold limits: readings within 5% of full-scale or ground indicate probable sensor open or short circuits. Short-circuit the RTD leads to simulate a zero-resistance fault; the ADC reading should drop to near zero volts corresponding to the instrumentation amplifier output offset voltage. Introduce a deliberate 10 Ω series resistance in one current-carrying lead to simulate lead resistance error; in a four-wire measurement, this perturbation should produce zero change in the temperature reading, demonstrating the lead resistance cancellation property. In contrast, inserting the 10 Ω resistor in series with a voltage-sensing lead should produce a significant temperature error due to the voltage drop across the added resistance corrupting the voltage measurement.

Quantify the thermal time constant of your RTD measurement system by executing a step response test. Heat the RTD element to 80°C by immersion in a hot water bath, then rapidly transfer it to a room-temperature (25°C) water bath while continuously recording temperature versus time at 10 Hz sample rate. Plot the cooling curve and fit an exponential decay model `T(t) = T_ambient + (T_initial - T_ambient) * exp(-t / tau)`, where `tau` represents the thermal time constant. A bare Pt100 element in water typically exhibits time constants of 1 to 3 seconds; larger values indicate poor thermal coupling between the RTD and the surrounding medium, while faster response suggests improved heat transfer or smaller thermal mass. Recognize that this measured time constant combines the intrinsic RTD thermal mass, the thermal resistance of the RTD package, and any protective sheath or thermowell surrounding the sensor—factors that dominate the dynamic response in practical installations far more than the electrical bandwidth of the signal conditioning circuit.

Document the complete uncertainty budget for your RTD measurement system by tabulating all contributing error sources. RTD element tolerance contributes ±0.3°C for Class B Pt100 devices at 0°C, increasing to ±0.8°C at 100°C per IEC 60751. Constant current source tolerance of ±0.1% contributes proportional resistance and temperature uncertainty. Instrumentation amplifier gain error of ±0.5% introduces span error. ADC integral nonlinearity of ±2 LSB at 12-bit resolution represents ±0.12% full-scale error. Reference voltage initial accuracy of ±0.1% partially cancels in ratiometric topologies but contributes to absolute voltage measurement uncertainty. Combine these independent error sources using root-sum-square methodology: `U_total = sqrt(U1^2 + U2^2 + ... + Un^2)`, where each `Ui` represents an individual uncertainty contribution expressed in common units. For this exercise, expect combined expanded uncertainty (k=2 coverage factor for approximately 95% confidence) near ±0.5°C after calibration, dominated by RTD element tolerance and thermal self-heating effects.

### Exercise 1B: Capacitive Proximity Sensor with Charge Amplifier Readout

Capacitive proximity sensors detect the approach of conductive or high-dielectric-constant objects through changes in electric field coupling and effective electrode capacitance. Unlike resistive sensors that require galvanic contact with the measurand, capacitive sensors operate through insulating barriers and noncontact standoff distances, enabling applications in liquid level sensing, touch interfaces, and non-invasive material property measurement. This exercise develops practical competency in charge amplifier circuit design, AC excitation signal generation, synchronous demodulation for amplitude recovery, and calibration techniques that establish quantitative distance measurement from raw capacitance variation.

The sensing element consists of a parallel-plate capacitor formed by a copper electrode pad with approximately 100 mm² area on one side of a printed circuit board, with the opposing capacitor plate provided by the approaching conductive object or grounded reference plane. For benchtop demonstration, fabricate the sensing electrode by adhering a 10 mm × 10 mm square of copper tape to a rigid insulating substrate such as FR4 PCB material or acrylic sheet. Connect a coaxial cable to the electrode with the center conductor soldered to the copper square and the shield terminated to circuit ground at the amplifier input only—not at the electrode—to avoid ground loop coupling while providing electrostatic shielding of the cable run. Position this sensing electrode parallel to a grounded metal plate or aluminum foil sheet mounted on a precision micrometer translation stage, establishing a controlled air gap distance from 0.1 mm to 10 mm.

The capacitance between parallel plates separated by air follows the fundamental electrostatics relationship `C = epsilon0 * A / d`, where `epsilon0 = 8.854 × 10^-12 F/m` represents the permittivity of free space, `A` denotes the overlapping electrode area in square meters, and `d` specifies the gap distance in meters. For a 100 mm² (0.0001 m²) electrode with 1 mm (0.001 m) spacing, the theoretical capacitance computes to `C = 8.854 × 10^-12 * 0.0001 / 0.001 = 0.885 pF`. At 10 mm spacing, capacitance reduces to 0.0885 pF. These sub-picofarad values demand charge amplifier topologies with femtofarad-level input capacitance and sub-picoamp input bias current to avoid overwhelming the sensor signal with amplifier parasitic loading and noise contributions.

Construct the charge amplifier circuit using an ultra-low-input-bias-current operational amplifier such as the OPA129 or LTC6268, featuring typical input bias currents below 10 fA and input capacitance under 2 pF. Configure the op-amp in transimpedance (current-to-voltage) topology with a feedback capacitor `Cf = 10 pF` connected between the inverting input and the output. The sensing electrode connects to the inverting input through a high-frequency coaxial cable with the shield grounded at the amplifier end only. A 10 MΩ feedback resistor in parallel with `Cf` provides DC bias stabilization by setting the low-frequency pole near 1.6 Hz—low enough to pass proximity signals but high enough to prevent DC drift from accumulating excessive output offset voltage. The non-inverting input connects to circuit ground through a matching 10 MΩ resistor to balance input bias current effects and minimize input offset voltage contribution.

Drive the sensing electrode with a 100 kHz sinusoidal excitation voltage generated by a microcontroller PWM peripheral followed by an analog reconstruction filter. Configure a 16-bit timer in center-aligned PWM mode with a carrier frequency of 10 MHz, yielding 100 discrete PWM duty cycle steps to synthesize the sine wave. Precompute a 100-element lookup table containing sine values from 0 to 2π, scaled to 16-bit unsigned integers representing duty cycles from 0% to 100%. The PWM interrupt service routine increments a phase accumulator and indexes the sine table, loading the retrieved value into the PWM compare register to update the duty cycle. This direct digital synthesis technique generates a 100 kHz sine wave with 1% THD (total harmonic distortion) before filtering.

Low-pass filter the PWM output using a third-order Butterworth topology with 200 kHz cutoff frequency to attenuate the 10 MHz carrier and higher-order PWM harmonics while passing the 100 kHz fundamental with less than 0.5 dB attenuation. Implement the filter as a cascade of Sallen-Key second-order and first-order RC stages using precision film capacitors and 1% metal-film resistors to maintain filter characteristic impedance and pole placement. The filtered sine wave drives a unity-gain buffer op-amp (OPA211 or AD8066) that isolates the filter from capacitive loading by the sensing electrode and coaxial cable. Adjust the PWM sine wave amplitude to ±2.5 V peak using a resistive voltage divider or programmable gain stage to constrain the charge amplifier output swing within the ADC input range while maximizing signal-to-noise ratio.

The charge amplifier output voltage follows the relationship `Vout = -Q / Cf = -(Vin * Cs) / Cf`, where `Vin` represents the excitation amplitude, `Cs` denotes the sensing electrode capacitance, and `Cf` specifies the feedback capacitor. For `Vin = 2.5 V`, `Cs = 0.885 pF`, and `Cf = 10 pF`, the output amplitude computes to `Vout = (2.5 * 0.885) / 10 = 0.221 V`. This output appears as a 100 kHz sine wave modulated in amplitude by proximity changes: as a conductive object approaches, the sensing capacitance increases, proportionally increasing the charge amplifier output amplitude. Extract this amplitude modulation via synchronous demodulation, multiplying the charge amplifier output by a reference sine wave phase-locked to the excitation and low-pass filtering the product to recover the DC-proportional amplitude term.

Implement synchronous demodulation in firmware by sampling the charge amplifier output with the ADC synchronized to the PWM excitation phase. Configure the ADC to trigger from the same timer that generates the PWM sine wave, phase-delayed by 90° (one-quarter cycle) to capture samples at the zero-crossings of the excitation waveform where the rate of change and hence capacitive current reaches maximum. Average 16 consecutive ADC samples acquired over one complete 100 kHz cycle to compute the amplitude envelope with effective synchronous detection bandwidth near 6.25 kHz—sufficient to capture proximity changes from hand motion and object approach while rejecting power-line harmonics and broadband electromagnetic interference.

Calibrate the capacitance-to-distance relationship by positioning the grounded reference plate at precisely known distances using the micrometer stage and recording the corresponding firmware amplitude readings. Establish calibration points at 0.5 mm, 1.0 mm, 2.0 mm, 5.0 mm, and 10.0 mm. Plot amplitude versus distance on logarithmic axes; the inverse relationship `C ∝ 1/d` appears as a straight line with slope near -1. Fit a power-law model `amplitude = k * d^-n` using least-squares regression, where `k` incorporates all gain factors and `n` should approximate 1.0 for ideal parallel-plate geometry. Deviations from unity slope indicate fringing field effects at large gap distances or finite electrode size effects that violate the infinite parallel-plate approximation.

Convert the fitted power-law model into a distance estimation function `d = (k / amplitude)^(1/n)` and implement this inverse function in firmware using a lookup table with linear interpolation for computational efficiency. Store 16 amplitude breakpoints spanning the calibrated range in flash memory, with corresponding distance values precomputed during calibration. For each runtime amplitude measurement, perform binary search to locate the bracketing breakpoint interval, then linearly interpolate: `d = d1 + (amplitude - a1) * (d2 - d1) / (a2 - a1)`. This table-and-interpolate approach executes in microseconds on modest microcontrollers while achieving interpolation error below 1% across the calibrated range—superior to naïve polynomial approximations that suffer from overfitting and numerical instability at range extrema.

Investigate the effect of dielectric materials by inserting a sheet of paper, plastic, or glass between the sensing electrode and the grounded reference plate. The effective capacitance increases by the relative permittivity (dielectric constant) of the inserted material: `C_material = epsilon_r * C_air`, where `epsilon_r = 1` for air, approximately 3 for paper and plastics, and 4 to 10 for common glasses. Measure the amplitude increase when a 1 mm thick polycarbonate sheet (epsilon_r ≈ 2.9) occupies a 2 mm air gap. The dielectric partially fills the gap, yielding composite capacitance computed as series combination of the air gap and dielectric layer: `1/C_total = 1/C_air + 1/C_dielectric`. This material-dependent response enables applications in liquid level sensing, where the dielectric constant of the process fluid (water epsilon_r ≈ 80, oil epsilon_r ≈ 2.5) modulates the sensor capacitance as the interface level crosses the electrode plane.

Characterize the parasitic capacitance contribution from PCB traces, coaxial cable, and amplifier input by measuring the output amplitude with the sensing electrode removed—leaving only the cable and PCB trace connected to the amplifier input. This parasitic capacitance, typically 5 to 20 pF depending on cable length and board layout, establishes the baseline offset that must be subtracted during calibration. High parasitic capacitance degrades sensitivity by reducing the fractional change in total capacitance for a given proximity variation; minimize parasitics through guarded-electrode PCB layout techniques where a grounded guard ring surrounds the sensing electrode trace and driven-shield coaxial cables where the shield carries a buffered replica of the electrode voltage to eliminate cable capacitance loading.

Diagnose common failure modes including excessive noise from inadequate shielding, sensitivity degradation from input bias current integrating on the feedback capacitor, and baseline drift from moisture absorption increasing PCB surface leakage. Verify shielding effectiveness by broadcasting a 1 MHz RF signal from a handheld transmitter near the sensor while monitoring the charge amplifier output for interference pickup; properly shielded systems show no detectable amplitude modulation. Test for bias-current-induced drift by monitoring the charge amplifier DC offset over 10 minutes with the excitation disabled; drift rates exceeding 10 mV/min indicate inadequate feedback resistance or contaminated PCB surfaces. Evaluate moisture sensitivity by breathing on the PCB and observing transient capacitance increases from water vapor condensation; conformal coating the PCB with acrylic or silicone improves moisture immunity in humid environments.

Quantify the distance resolution and minimum detectable proximity change by computing the RMS noise on the amplitude signal with the grounded reference plate stationary at 2 mm distance. Record 1000 samples at 1 kHz rate, compute the standard deviation, and divide by the sensitivity `dA/dd` obtained from the calibration curve slope at 2 mm. For a typical implementation achieving 10 mV RMS noise and 200 mV/mm sensitivity, the distance resolution computes to `10 mV / 200 mV/mm = 0.05 mm`—adequate for touch detection and crude position sensing but insufficient for precision metrology. Improve resolution by increasing excitation amplitude, reducing feedback capacitor value to increase transimpedance gain, lengthening the synchronous demodulation integration time, or averaging multiple measurements—each tradeoff balanced against bandwidth reduction, dynamic range compression, or increased latency.

## Exercise 2: Parameter Variation & Empirical Analysis

### Exercise 2A: MEMS Accelerometer Calibration and Cross-Axis Coupling Characterization

Microelectromechanical systems (MEMS) accelerometers transduce acceleration into electrical signals through displacement-modulated capacitance or piezoresistive stress effects in suspended silicon proof masses. While digital-output MEMS accelerometers with integrated analog-to-digital conversion and I2C/SPI interfaces dominate consumer applications, this exercise examines analog-output accelerometers with external signal conditioning to expose the full measurement chain and develop intuition for error sources including zero-g offset, scale factor variation, cross-axis sensitivity, and temperature-dependent drift. The experimental workflow progresses from single-axis static tilt calibration through multi-position six-point tumble calibration to dynamic frequency response characterization, culminating in a complete error model suitable for navigation-grade inertial measurement unit (IMU) applications.

Select an analog-output MEMS accelerometer such as the ADXL335 (triple-axis, ±3 g range, 0.3 V/g sensitivity) or ADXL377 (triple-axis, ±200 g range, 6.5 mV/g sensitivity), mounted on a breakout PCB with power supply decoupling and header pins for easy breadboard integration. The accelerometer outputs three analog voltages, one per axis, centered near the mid-supply voltage (typically 1.65 V for 3.3 V operation) and varying proportionally with acceleration. For the ADXL335, the X, Y, and Z axis outputs swing ±900 mV around 1.65 V for ±3 g input acceleration, yielding the specified 300 mV/g sensitivity. At 1 g gravitational acceleration in any axis, the output shifts by ±300 mV relative to the zero-g offset, establishing the static tilt measurement principle.

Construct the signal conditioning interface by connecting each accelerometer axis output to a unity-gain buffer amplifier (AD8606 or OPA2340) to provide low output impedance for driving the ADC input and coaxial cables to oscilloscope probe points. Buffer all three axes independently, even if only one or two axes are initially used, to permit simultaneous multi-axis data acquisition without channel interaction. Implement a triple-channel sequential ADC acquisition routine in firmware, triggered by a 1 kHz timer interrupt for consistent sample timing. The zero-g offset calibration determines the accelerometer output voltage when no acceleration acts along the sensitive axis—an impossibility in Earth's gravitational field, requiring algebraic inference from multiple orientation measurements. For initial single-axis calibration, orient the accelerometer PCB with the sensitive axis horizontal, perpendicular to the gravity vector, so gravitational acceleration projects zero component along that axis. Secure the PCB to a flat reference surface using a machinist's tooling vise and verify horizontal orientation using a precision bubble level or digital inclinometer with resolution better than 0.1°. Record 1000 samples and compute the mean output voltage; this value represents the zero-g offset for the horizontal axis within the uncertainty contribution of residual tilt angle. For the ADXL335, expect zero-g offset near 1.65 V ± 50 mV due to component tolerances and residual tilt.

Next, rotate the accelerometer assembly by 180° around the horizontal axis perpendicular to the sensitive axis under test, inverting the orientation while maintaining the sensitive axis horizontal. Record another 1000-sample ensemble and compute the mean. The difference between these two measurements reflects only mechanical tilt error and accelerometer noise, confirming that the sensitive axis remains perpendicular to gravity within measurement uncertainty. Now rotate the assembly 90° to position the sensitive axis vertical with the positive direction aligned with gravity (i.e., PCB laying flat with the accelerometer Z-axis pointing upward). Record 1000 samples; the mean output should increase by the scale factor: `V_+1g = V_0g + sensitivity * 1 g`. For ADXL335, expect `V_+1g ≈ 1.65 V + 0.300 V = 1.95 V`.

Flip the assembly to position the sensitive axis vertical with the negative direction aligned with gravity (PCB inverted). Record 1000 samples; the mean output should decrease by the scale factor: `V_-1g = V_0g - sensitivity * 1 g`, yielding approximately `1.65 V - 0.300 V = 1.35 V` for the ADXL335. These four measurements—horizontal (0 g), horizontal inverted (0 g verification), vertical up (+1 g), and vertical down (-1 g)—provide redundant data for solving the two-parameter linear model: `output = offset + sensitivity * acceleration`. Compute the zero-g offset as the mean of the two vertical measurements: `offset = (V_+1g + V_-1g) / 2`, which algebraically cancels the scale factor. Compute the sensitivity as half the difference: `sensitivity = (V_+1g - V_-1g) / 2 g`, which isolates the scale factor from the offset.

Apply this single-axis calibration independently to the X, Y, and Z axes, generating three offset and three sensitivity coefficients stored in nonvolatile memory. These coefficients convert raw ADC voltages to calibrated acceleration via `accel_X = (V_X - offset_X) / sensitivity_X`, and similarly for Y and Z axes. Verify the calibration by positioning the accelerometer in arbitrary orientations and confirming that the vector magnitude `sqrt(accel_X^2 + accel_Y^2 + accel_Z^2)` equals 1 g within ±5% measurement uncertainty—a self-consistency check that leverages the known constant magnitude of Earth's gravity vector.

The six-point tumble calibration extends single-axis tilt calibration to account for cross-axis coupling and non-orthogonality errors. Position the accelerometer in six orthogonal orientations: X-axis up, X-axis down, Y-axis up, Y-axis down, Z-axis up, and Z-axis down. In each orientation, record 1000-sample ensembles from all three axes simultaneously. Construct a 6×3 matrix of mean voltages where rows correspond to orientations and columns correspond to axes. Ideally, each column exhibits two large-magnitude values near ±(offset + sensitivity) and four small values near offset, but real accelerometers show nonzero off-axis readings due to cross-axis sensitivity—typically specified as 1% to 5% of the primary axis sensitivity.

Formulate the calibration problem as a linear system: `V = S * A + O`, where `V` is the 6×3 voltage matrix, `S` is the 3×3 sensitivity matrix (diagonal elements represent primary axis sensitivities, off-diagonal elements represent cross-axis coupling), `A` is the 6×3 applied acceleration matrix (±1 g along one axis, 0 along others), and `O` is the 1×3 offset vector. Solve for `S` and `O` using least-squares regression or direct matrix inversion. The resulting sensitivity matrix `S` corrects for both scale factor errors and cross-axis coupling via the transformation `accel_corrected = S^-1 * (V_measured - O)`. Implement this matrix multiplication in firmware as three multiply-accumulate sequences, accepting the nine-element `S^-1` matrix and three-element offset vector as calibration parameters.

Quantify cross-axis sensitivity by examining the off-diagonal elements of the calibration matrix `S`. For a typical consumer-grade MEMS accelerometer, expect X-into-Y coupling near 0.03 g/g, meaning 3% of X-axis acceleration appears as a spurious signal on the Y-axis. Cross-axis errors arise from non-orthogonal proof mass suspension geometry, residual stress-induced misalignment, and package-level mounting tolerances. High-performance tactical-grade MEMS accelerometers specify cross-axis sensitivity below 0.5%, achieved through precision wafer-level alignment and active trim during factory calibration. Characterize your device by applying pure X-axis acceleration (e.g., +1 g via vertical mounting) and recording the ratio `accel_Y / accel_X` after calibration; this ratio directly quantifies residual cross-axis coupling not fully corrected by the linear matrix model.

Temperature-induced drift represents a persistent challenge in MEMS accelerometer applications. As ambient temperature changes, thermal expansion mismatches between the silicon die, package substrate, and PCB generate stress gradients that couple into the proof mass suspension, producing apparent acceleration offsets. Additionally, the piezoresistive or capacitive transduction mechanisms exhibit intrinsic temperature coefficients. Characterize temperature drift by placing the calibrated accelerometer assembly in a temperature-controlled chamber or oven, recording zero-g offset values at 10°C intervals from -20°C to +60°C. Plot offset versus temperature for each axis; expect linear drift coefficients ranging from 0.1 mg/°C to 1 mg/°C for consumer devices. Store these temperature coefficients in nonvolatile memory and implement firmware compensation: `accel_compensated = accel_calibrated - TC * (T_current - T_ref)`, where `TC` represents the temperature coefficient vector determined experimentally and `T_current` is measured by the microcontroller's on-chip temperature sensor.

Dynamic frequency response characterization reveals bandwidth limitations imposed by mechanical resonance of the MEMS proof mass and electrical filtering in the output stage. Mount the accelerometer assembly on a mechanical shaker driven by a frequency-swept sine wave from 10 Hz to 1 kHz. Alternatively, construct a crude shaker using a loudspeaker with the accelerometer PCB attached to the speaker cone. Drive the speaker with a swept sine wave from a function generator, starting at 10 Hz and logarithmically sweeping to 1 kHz over 30 seconds. Synchronously record the accelerometer output and the shaker drive voltage (as a reference signal). Compute the magnitude ratio and phase lag between output and input versus frequency using FFT-based spectral analysis or a lock-in amplifier. The resulting Bode plot reveals the -3 dB bandwidth, typically 50 Hz to 500 Hz for consumer MEMS accelerometers, and mechanical resonance peaks near 1 kHz to 5 kHz where the proof mass suspension exhibits under-damped oscillation.

Shock survivability and saturation behavior are validated by subjecting the accelerometer to impulsive mechanical inputs exceeding the rated measurement range. Drop the accelerometer assembly from a measured height onto a rigid surface (e.g., concrete floor) to generate high-g impacts. Free-fall drop height `h` produces impact acceleration `a = sqrt(2 * g * h / d)` where `d` represents the deformation depth during impact—typically 1 mm to 10 mm for plastic or foam landing surfaces. A 1-meter drop onto a 5 mm foam pad generates approximately `a = sqrt(2 * 9.81 * 1.0 / 0.005) ≈ 63 g` peak acceleration. Configure the ADC and firmware for maximum sample rate (e.g., 10 kHz) to capture the transient waveform. Verify that the output saturates at the accelerometer's specified maximum output voltage without introducing permanent offset drift or mechanical damage. Repeat 10 times to confirm shock survival margin.

Allan variance analysis quantifies the noise and stability characteristics of the accelerometer measurement system across time scales from milliseconds to hours. Collect a continuous data stream of 1 million samples at 1 kHz with the accelerometer stationary in a thermally stable environment. Compute Allan deviation: for each averaging time `tau`, partition the data into non-overlapping bins of length `tau`, compute the mean of each bin, then compute the standard deviation of the differences between consecutive bin means scaled by `sqrt(2)`. Plot Allan deviation versus averaging time on logarithmic axes. The resulting curve reveals several noise regimes: white noise (slope -½), bias instability (flat minimum), and rate random walk (slope +½ at long time scales). The minimum point identifies the optimal measurement averaging time that balances noise reduction against drift accumulation; typical consumer MEMS accelerometers exhibit bias instability near 0.1 mg to 1 mg at integration times of 10 seconds to 100 seconds.

### Exercise 2B: Thermocouple Cold Junction Compensation and Linearization

Thermocouples generate small thermoelectric voltages—tens of microvolts per degree Celsius—proportional to the temperature difference between the measurement junction (hot junction) and the reference junction (cold junction). Unlike RTDs that measure absolute temperature via resistance change, thermocouples inherently measure temperature difference, requiring precise knowledge of the cold junction temperature to infer the absolute hot junction temperature. This exercise develops proficiency in analog thermocouple signal conditioning, precision cold junction temperature measurement using silicon bandgap sensors, polynomial linearization of thermocouple nonlinearity, and ice-point reference validation techniques fundamental to industrial temperature metrology.

Select a Type K thermocouple (chromel-alumel alloy) providing the best compromise between cost, linearity, and temperature range (−200°C to +1350°C) with a nominal Seebeck coefficient near 41 µV/°C at room temperature. Purchase a thermocouple probe with molded connector or bare thermocouple wire with standard miniature thermocouple connectors to avoid accidental polarity reversal. The positive (chromel) lead typically exhibits yellow insulation, while the negative (alumel) lead is red. Verify polarity by connecting the thermocouple to a high-impedance voltmeter and heating the measurement junction with a soldering iron; a positive voltage reading confirms correct polarity.

Construct the cold junction compensation subsystem using a precision analog temperature sensor IC such as the LM35 (10 mV/°C linear voltage output), TMP36 (10 mV/°C centered at 0.5 V for negative temperature capability), or MCP9700 (10 mV/°C with 0.5 V offset). Mount the temperature sensor IC in direct thermal contact with the thermocouple reference junction connection point—typically a screw terminal block or PCB-mounted connector. Ensure intimate thermal coupling by applying thermal compound between the sensor package and the terminal block, then wrapping the assembly in foam insulation to minimize thermal gradients between the sensor and the reference junction. Temperature measurement errors at the cold junction propagate directly as hot junction errors with unity gain, making cold junction accuracy the limiting factor in many practical thermocouple systems.

The thermocouple voltage amplifier requires ultra-low offset voltage (below 10 µV), low drift (below 0.1 µV/°C), high common-mode rejection (above 100 dB), and low input bias current to avoid voltage drop errors across thermocouple lead resistance. Use a precision instrumentation amplifier such as the INA126, AD8221, or LT1167 configured for a gain of 500 to amplify the 41 µV/°C Type K sensitivity to 20.5 mV/°C at the amplifier output—comfortably measurable by a 12-bit ADC with 2.5 V reference yielding 0.61 mV/LSB resolution and approximately 0.03°C quantization. Connect the thermocouple leads directly to the instrumentation amplifier differential inputs without series resistors, minimizing thermoelectric EMF generation from dissimilar metal junctions at resistor leads.

Implement isothermal input termination by routing both thermocouple leads to a common copper terminal block where the cold junction reference temperature sensor mounts. All copper-to-thermocouple metal transitions occur at this single isothermal point, eliminating parasitic thermocouples from wire-to-PCB solder joints distributed at different temperatures. For additional thermal isolation, enclose the terminal block and temperature sensor in a small aluminum block with high thermal mass, damping rapid temperature fluctuations and establishing a well-defined isothermal reference temperature. Avoid routing thermocouple extension wire across temperature gradients or near heat-generating components; a 10°C gradient across one meter of copper extension wire generates parasitic thermovoltages near 0.4 µV due to copper's 0.04 µV/°C Seebeck coefficient—small but measurable against the thermocouple signal.

Configure the microcontroller ADC for dual-channel simultaneous acquisition, sampling both the amplified thermocouple voltage and the cold junction temperature sensor voltage synchronously to avoid errors from temperature drift during sequential channel conversion. A 12-bit ADC with 2.500 V reference provides 0.61 mV/LSB resolution, translating to 0.61 mV / 20.5 mV/°C ≈ 0.03°C quantization on the hot junction temperature after cold junction compensation. Apply 16× oversampling to achieve 14-bit effective resolution (0.0075°C quantization) and implement a 16-tap FIR low-pass filter with 1 Hz corner frequency to reject power-line interference and high-frequency noise pickup on the thermocouple leads.

The cold junction compensation algorithm combines the measured thermocouple voltage with the cold junction temperature to compute the absolute hot junction temperature. First, convert the cold junction temperature sensor voltage to temperature using the sensor calibration equation: `T_CJ = (V_sensor - 0.5 V) / 0.01 V/°C` for TMP36. Next, use the NIST ITS-90 Type K thermocouple inverse polynomial to convert `T_CJ` to the equivalent thermocouple voltage `V_CJ` that would be generated by a thermocouple with its hot junction at `T_CJ` and cold junction at 0°C. Add this voltage to the measured thermocouple voltage: `V_total = V_measured + V_CJ`. Finally, apply the NIST forward polynomial to convert `V_total` to the hot junction temperature `T_HJ`.

NIST provides piecewise polynomial approximations for Type K thermocouples with the forward polynomial (voltage to temperature) covering the range -200°C to 1372°C split into two regions. For -200°C to 0°C, use the polynomial `T = sum(c[i] * E^i for i in 0 to 8)` where `E` represents thermoelectric voltage in millivolts and coefficients `c[0] = 0.0000000`, `c[1] = 2.5173462e+1`, `c[2] = -1.1662878`, `c[3] = -1.0833638`, `c[4] = -8.9773540e-1`, `c[5] = -3.7342377e-1`, `c[6] = -8.6632643e-2`, `c[7] = -1.0450598e-2`, `c[8] = -5.1920577e-4`. For 0°C to 1372°C, use `c[0] = 0.000000`, `c[1] = 2.508355e+1`, `c[2] = 7.860106e-2`, `c[3] = -2.503131e-1`, `c[4] = 8.315270e-2`, `c[5] = -1.228034e-2`, `c[6] = 9.804036e-4`, `c[7] = -4.413030e-5`, `c[8] = 1.057734e-6`, `c[9] = -1.052755e-8`.

Implement the polynomial evaluation in firmware using Horner's method for numerical stability and computational efficiency. Instead of computing `c[0] + c[1]*E + c[2]*E^2 + ...` which requires repeated exponentiation, factor as `c[0] + E*(c[1] + E*(c[2] + E*(c[3] + ...)))`, requiring only n multiplications for an n-th order polynomial. Store the coefficients in flash memory as single-precision floating-point constants and perform the computation in floating-point arithmetic; conversion from voltage in millivolts to temperature in degrees Celsius executes in under 20 microseconds on a 100 MHz Cortex-M4 processor with hardware floating-point unit.

The inverse polynomial (temperature to voltage) is required for cold junction compensation to convert the measured cold junction temperature `T_CJ` to the equivalent voltage. For Type K, the 0°C to 1372°C range uses the polynomial `E = sum(c[i] * T^i for i in 0 to 10) + a0*exp(a1*(T - a2)^2)` where `E` is in millivolts, `T` in degrees Celsius, and coefficients `c[0] = 0.000000`, `c[1] = 3.9450128e-2`, `c[2] = 2.3622373e-5`, `c[3] = -3.2858906e-7`, `c[4] = -4.9904828e-9`, `c[5] = -6.7509059e-11`, `c[6] = -5.7410327e-13`, `c[7] = -3.1088872e-15`, `c[8] = -1.0451379e-17`, `c[9] = -1.9889266e-20`, `c[10] = -1.6322697e-23`, with exponential correction terms `a0 = 1.185976e+2`, `a1 = -1.183432e-4`, `a2 = 1.269686e+3`. This exponential term corrects for magnetic transition effects in chromel alloy near 800°C; omit it for sub-800°C applications to reduce computational cost.

Quantify the residual nonlinearity after polynomial correction by establishing intermediate reference temperatures using a precision temperature-controlled aluminum block with drilled insertion holes and a calibrated reference thermometer. Reverse the thermocouple polarity; the temperature reading should invert around the cold junction temperature, reading `T_HJ = 2*T_CJ - T_actual` due to sign inversion of the measured thermoelectric voltage.

Upon removing illumination, these trapped carriers must recombine before the photodiode can respond to low-light inputs—a phenomenon called saturation recovery or photodiode blooming. Measure the time constant of the exponential decay from saturation voltage back to dark current baseline; expect recovery times from 100 µs to 10 ms depending on photodiode junction capacitance and reverse bias conditions. For applications requiring rapid recovery from overload—such as laser rangefinder receivers that must detect weak returns shortly after transmitting intense pulses—use PIN photodiodes with active reverse bias voltage (10 V to 100 V) to reduce junction capacitance and accelerate charge carrier sweep-out.

Quantify electromagnetic interference coupling by operating the photodiode near high-power RF transmitters or switching power supplies. The photodiode junction capacitance and transimpedance amplifier feedback network form a high-impedance antenna that rectifies incident RF signals into DC or low-frequency interference modulating the optical measurement. Demonstrate this by keying a VHF/UHF handheld radio near the photodiode assembly while monitoring output voltage; expect interference amplitude proportional to transmit power and inversely proportional to distance. Mitigate RF interference through metal enclosure shielding with conductive gaskets, transimpedance amplifier input guard rings connected to virtual ground, and ferrite bead filtering on power supply and signal output lines. Verify shielding effectiveness by repeating the interference test with the enclosure closed; residual interference below 0.1% of full-scale indicates adequate RF immunity.

Document the complete dynamic range performance by constructing an irradiance-versus-output table spanning nine decades from 10 nW/cm² (dark room) to 100 mW/cm² (direct sunlight). For each decade, record the active gain range, ADC output value, computed optical power, and residual linearity error relative to the calibrated responsivity. A properly designed photodiode system with three-range automatic gain switching achieves 120 dB instantaneous dynamic range (six decades) within any single gain range, extended to 140 dB (nine decades) total usable range across all three ranges after accounting for noise floor and saturation limits. This performance rivals commercial radiometers and lux meters costing thousands of dollars, demonstrating the practical value of careful analog front-end design and multi-range switching architectures in precision optical instrumentation.

### Exercise 3B: Strain Gauge Load Cell Calibration Under Overload and Hysteresis Characterization

Resistive strain gauges bonded to elastic structural elements form load cells that convert applied force or torque into measurable resistance changes through the piezoresistive effect in thin metallic foil patterns. Industrial load cells specify rated capacity (maximum safe operating load), overload capacity (maximum load before permanent damage), and hysteresis (maximum deviation between loading and unloading curves expressed as a percentage of full-scale output). This final exercise subjects a strain-gauge-based load cell to carefully controlled overload conditions approaching 150% rated capacity while characterizing nonlinearity, hysteresis, creep, and permanent zero shift to develop diagnostic competency in mechanical sensor failure modes and recovery protocols essential for high-reliability force measurement in aerospace, industrial weighing, and structural health monitoring applications.

Construct a simple beam-type load cell from a 6061-T6 aluminum bar with dimensions 100 mm length × 10 mm width × 3 mm thickness. Bond a foil strain gauge (such as Vishay Micro-Measurements EA-06-125AD-120) to the top surface of the beam at midspan using cyanoacrylate adhesive, following the manufacturer's surface preparation protocol: degrease with isopropanol, abrade with 400-grit silicon-carbide paper, neutralize with acidic surface conditioner, apply thin cyanoacrylate layer, position the gauge, and cure under pressure for 1 hour at room temperature. The strain gauge consists of a meandering constantan foil pattern with 120 Ω nominal resistance and gauge factor `GF ≈ 2.1`, meaning the resistance changes by 2.1 Ω per Ω for each 1000 µε (microstrain) of mechanical strain along the sensitive axis.

Bond an identical dummy strain gauge to an unstressed section of the same aluminum beam, oriented perpendicular to the active gauge to cancel temperature effects while rejecting transverse strain. These two gauges form two arms of a Wheatstone bridge, with the remaining two arms completed by precision 120 Ω resistors (0.1% tolerance, ±25 ppm/°C temperature coefficient). Excite the bridge with 5.000 V from a precision voltage reference (ADR4550 or LM399), generating approximately 20.8 mA bridge current. At zero applied load, balance the bridge by adjusting a 10 kΩ potentiometer in series with one bridge resistor until the differential output voltage measured between the midpoints of the two bridge legs equals zero within ±0.1 mV.

Connect the bridge output to an instrumentation amplifier configured for a gain of 1000 to amplify the small differential bridge voltage to a level suitable for ADC acquisition. For the specified aluminum beam geometry loaded at midspan, classical mechanics predicts maximum surface strain `ε = 3 * F * L / (2 * E * w * t^2)`, where `F` represents applied force in newtons, `L = 0.1 m` is the beam length, `E = 69 GPa` is the elastic modulus of aluminum, `w = 0.01 m` is the beam width, and `t = 0.003 m` is the beam thickness. Substituting values: `ε = 3 * F * 0.1 / (2 * 69e9 * 0.01 * 0.003^2) = 2.42e-8 * F` strain per newton of applied force. For a 1000 N (approximately 100 kg) applied force, the maximum strain computes to 24.2 µε.

The strain gauge resistance change follows `ΔR / R = GF * ε`, yielding `ΔR / 120 Ω = 2.1 * 24.2e-6 = 50.8e-6` or 6.1 mΩ resistance increase for 1000 N load. This resistance change unbalances the Wheatstone bridge, generating differential output voltage `Vout = Vex * (ΔR/R) / 4` for a quarter-bridge configuration where only one active gauge varies. For `Vex = 5.000 V` and `ΔR/R = 50.8e-6`, the bridge output computes to `Vout = 5.000 * 50.8e-6 / 4 = 63.5 µV` per 1000 N. The 1000× instrumentation amplifier gain scales this to 63.5 mV per 1000 N, or 0.0635 mV/N sensitivity at the ADC input.

Construct a mechanical loading fixture by mounting the aluminum beam in a cantilever configuration with one end rigidly clamped in a machinist's vise and the free end extending horizontally. Suspend calibrated masses from the free end using a lightweight wire loop to apply known gravitational forces. Start with 100 g (0.98 N), then incrementally add masses in 100 g increments up to 10 kg (98 N). For each applied mass, allow 30 seconds for creep stabilization, then record 100 ADC samples and compute the mean output voltage. Plot output voltage versus applied force; the relationship should be linear with slope matching the predicted 0.0635 mV/N sensitivity within ±5% uncertainty from strain gauge factor tolerance, bridge resistor tolerance, and aluminum modulus variation.

Perform two-point calibration by recording output voltage at zero load (all masses removed) and at rated capacity (10 kg applied). Compute the offset as the zero-load voltage and the span as the voltage change per newton: `span = (V_10kg - V_0kg) / (10 kg * 9.81 m/s^2)`. Store these calibration coefficients in nonvolatile memory and apply the linear transformation `Force = (V_measured - offset) / span` to convert all subsequent voltage measurements to force in newtons. Verify calibration accuracy by applying intermediate loads (2 kg, 5 kg, 8 kg) and confirming that the computed force agrees with the known applied mass within ±1% measurement uncertainty.

Execute a loading-unloading hysteresis test by incrementally loading the beam from zero to full scale in 1 kg steps, then unloading in the same 1 kg decrements back to zero. At each step, record the output voltage after 30-second stabilization. Plot output voltage versus applied force for both loading and unloading curves on the same axes. The loading curve traces the sensor response as force increases; the unloading curve traces the response as force decreases. Ideal elastic behavior produces coincident loading and unloading curves, but real mechanical structures exhibit hysteresis—the maximum separation between curves—arising from friction in the adhesive bond interface, microplastic deformation in the aluminum substrate, and residual stress relaxation in the strain gauge foil.

Quantify hysteresis as the maximum vertical separation between loading and unloading curves expressed as a percentage of full-scale output (FSO). For a well-constructed strain gauge load cell with proper adhesive curing and surface preparation, expect hysteresis below 0.1% FSO, corresponding to maximum voltage difference less than 6.35 µV or equivalent force error of 1 N at 1000 N capacity. Higher hysteresis values indicate poor bond quality, contaminated bonding surface, or substrate material operating beyond its elastic limit. Repeat the hysteresis test at 25°C, 40°C, and 60°C to characterize temperature dependence of hysteresis; elastomeric adhesives exhibit increasing hysteresis with temperature due to reduced shear modulus and enhanced viscoelastic creep.

Apply a controlled overload by suspending 15 kg (147 N) from the free end—150% of the rated 10 kg capacity. Monitor the output voltage continuously during load application and holding period. Initially, voltage increases linearly with load following the calibrated sensitivity, but as stress approaches the aluminum yield strength (approximately 275 MPa for 6061-T6), the response begins to deviate upward from linearity indicating plastic deformation initiation. Hold the overload for 5 minutes while recording output voltage at 1 Hz sample rate; observe gradual voltage increase (creep) as the aluminum substrate undergoes time-dependent plastic flow. Remove the overload and record the zero-load output voltage; if it differs from the original zero-point by more than 0.2% FSO, permanent zero shift has occurred, indicating irreversible plastic deformation or adhesive bond degradation—a failure condition requiring load cell replacement.

Characterize creep behavior by applying a constant 5 kg load and recording output voltage continuously for 1 hour at 0.1 Hz sample rate. Plot voltage versus time on semi-logarithmic axes; creep typically follows a logarithmic time dependence `V(t) = V0 + k * log(t)` where `V0` represents the instantaneous response and `k` quantifies creep magnitude. For metallic strain gauges on aluminum substrates at room temperature, expect creep below 0.05% FSO per decade of time (e.g., voltage changes by less than 3.2 µV when comparing 10-second and 100-second readings). Higher creep rates indicate viscoelastic adhesive layers or substrate materials with poor dimensional stability. Low-creep load cells use glass-fiber-reinforced epoxy adhesives, stress-relieved substrates, and temperature-compensated dummy gauges to achieve creep specifications below 0.02% FSO per decade.

Investigate temperature compensation by heating the load cell assembly in a temperature-controlled oven from 25°C to 60°C while maintaining constant zero load. Record output voltage every 5°C increment; expect voltage drift arising from two mechanisms: differential thermal expansion between the aluminum substrate and constantan strain gauge foil (apparent strain) and resistance temperature coefficient mismatch between active and dummy gauges. The dummy gauge configuration cancels first-order temperature effects when both gauges experience identical temperature changes, but thermal gradients across the structure produce residual temperature sensitivity. Plot output voltage versus temperature; ideally, the slope should be near zero (less than 0.01% FSO/°C). Significant temperature drift indicates improper dummy gauge placement or differential heating between active and dummy gauge locations.

Apply a sudden impact load by dropping a 1 kg mass from 10 cm height onto a padded surface affixed to the load cell. The impact generates peak force `F_peak = m * v / Δt`, where `v = sqrt(2 * g * h) = 1.4 m/s` represents the impact velocity and `Δt` denotes the contact duration (typically 1 ms to 10 ms depending on padding compressibility). For `Δt = 5 ms`, the peak force computes to `F_peak = 1 kg * 1.4 m/s / 0.005 s = 280 N`—nearly 30 times the static weight of the mass. Capture the transient response on an oscilloscope or high-speed data acquisition system sampling at 10 kHz minimum. Observe that the output exhibits a sharp initial peak followed by damped oscillation at the beam's natural frequency (typically 50 Hz to 200 Hz for the specified geometry). Verify that the peak amplitude corresponds to the predicted impact force based on momentum transfer principles and that the load cell returns to zero baseline after ringing decays, confirming no permanent damage from the impact overload.

## Operational Reference Guide & Diagnostic Checklist

This reference guide consolidates key sensor interface topologies, failure mode signatures, and diagnostic procedures into a practitioner-focused quick-reference format for benchtop troubleshooting and field deployment verification. Organized by sensor modality, each section provides the minimal essential information required to establish correct interface connections, interpret common fault conditions, and execute first-pass troubleshooting before resorting to oscilloscope-level circuit analysis or firmware debugging.

**Resistive Sensor Interfaces (RTD, Thermistor, Strain Gauge)**

- **Preferred topology:** Four-wire Kelvin connection for resistance below 1 kΩ to eliminate lead resistance errors; two-wire acceptable for resistance above 10 kΩ where lead contribution remains below 0.1% measurement uncertainty.
- **Signal conditioning:** Wheatstone bridge excitation with instrumentation amplifier differential output pickup provides inherent common-mode rejection and ratiometric measurement immunity to supply voltage variation.
- **Excitation limits:** Limit current to maintain self-heating temperature rise below 0.1°C for temperature sensors; typical limits are 1 mA for Pt100 RTDs, 0.1 mA for thermistors, 10 mA for strain gauges.
- **Open-circuit signature:** ADC reading saturates near supply rail; instrumentation amplifier output slews to positive or negative limit depending on which bridge arm opens.
- **Short-circuit signature:** ADC reading drops to near zero (typically within 10 mV of ground); bridge becomes severely unbalanced.
- **Drift failure:** Gradual offset change over minutes to hours indicates moisture absorption, solder joint corrosion, or reference voltage drift; rule out sensor element failure by substituting known-good reference sensor.

**Thermocouple Interfaces**

- **Preferred topology:** Isothermal cold junction with precision temperature sensor (LM35, TMP36) in direct thermal contact; instrumentation amplifier with ultra-low offset voltage (below 10 µV) and high common-mode rejection.
- **Junction types:** Type K (chromel-alumel) for general purpose, Type T (copper-constantan) for cryogenic, Type J (iron-constantan) for reducing atmospheres, Type S (platinum-rhodium) for high temperature above 1000°C.
- **Open thermocouple signature:** Output voltage changes erratically with temperature instead of smoothly; often reads high temperature or jumps to instrument maximum; caused by broken wire or poor connector contact.
- **Reversed polarity signature:** Temperature reading inverts around cold junction temperature; adding heat causes reading to decrease; verify correct color-coding (Type K: yellow = positive, red = negative).
- **Cold junction error:** Fixed offset approximately equal to room temperature (typically +20°C to +25°C); indicates cold junction compensation algorithm disabled or temperature sensor disconnected.
- **EMI signature:** Temperature reading exhibits high-frequency noise or 50/60 Hz modulation; use twisted-pair extension wire and differential amplifier input filtering; verify thermocouple shielding connects to circuit ground at amplifier end only to avoid ground loops.

**Capacitive Sensor Interfaces**

- **Preferred topology:** Charge amplifier with ultra-low-input-bias-current op-amp (OPA129, LTC6268) and feedback capacitor establishing transimpedance gain; AC excitation via PWM synthesis followed by analog reconstruction filter.
- **Excitation frequency:** 10 kHz to 1 MHz depending on cable capacitance; higher frequencies improve signal-to-noise ratio but require faster op-amps to maintain loop stability; avoid power-line harmonics (50/60 Hz and multiples).
- **Parasitic capacitance:** Minimized through guard ring layout surrounding sensing electrode trace on PCB and driven-shield coaxial cables where shield carries buffered replica of electrode voltage.
- **Saturation signature:** Output signal clips or becomes distorted when high-dielectric-constant material (water, metal) approaches electrode too closely; reduce excitation amplitude or increase feedback capacitor to restore linear operating region.
- **Baseline drift:** Gradual capacitance increase over hours indicates moisture absorption on PCB surface or in dielectric layers; apply conformal coating and verify proper desiccant protection in sealed enclosures.
- **Interference pickup:** 50/60 Hz modulation of output signal indicates inadequate shielding; capacitive coupling from nearby AC power wiring appears as amplitude modulation of excitation carrier; verify metal enclosure provides >40 dB shielding effectiveness.

**MEMS Accelerometer Interfaces**

- **Preferred topology:** Analog-output accelerometer with external buffer amplifiers and microcontroller ADC acquisition; digital I2C/SPI accelerometers acceptable for lower-performance applications but conceal raw sensor characteristics.
- **Coordinate frame:** Verify accelerometer mounting orientation matches PCB silkscreen axis labels; Z-axis typically points perpendicular to PCB plane, X and Y parallel to PCB edges.
- **Zero-g offset:** 1.65 V ± 0.15 V for 3.3 V supply (ADXL335), 2.5 V ± 0.2 V for 5 V supply; deviations exceeding ±0.3 V indicate supply voltage fault or damaged accelerometer.
- **Scale factor:** 300 mV/g for ±3 g range (ADXL335), 6.5 mV/g for ±200 g range (ADXL377); verify by measuring +1 g and −1 g gravity alignment using tilt fixture; scale factor error exceeding ±10% indicates accelerometer failure.
- **Cross-axis sensitivity:** Should be below 5% for consumer devices; verified by applying pure single-axis acceleration and observing perpendicular axis outputs remain within 5% of primary axis reading.
- **Shock damage signature:** Sudden permanent zero-g offset shift exceeding 0.5 g after impact event indicates cracked MEMS die or broken bond wire; accelerometer requires replacement.
- **Temperature drift:** 0.1 mg/°C to 1 mg/°C typical for consumer devices; implement firmware temperature compensation using on-chip temperature sensor and empirically determined temperature coefficients.

**Photodiode Interfaces**

- **Preferred topology:** Transimpedance amplifier with switchable feedback resistor values (100 kΩ, 1 MΩ, 10 MΩ) for automatic range extension; photoconductive mode (zero external bias) for maximum linearity and minimum dark current.
- **Feedback capacitor:** 10 pF parallel to feedback resistor establishes pole for loop stability; pole frequency `f_pole = 1 / (2 * π * Rf * Cf)` determines bandwidth (approximately 1.6 kHz for 10 MΩ resistor, 16 kHz for 1 MΩ, 160 kHz for 100 kΩ).
- **Dark current:** 1 pA to 100 pA at 25°C, doubling every 10°C temperature rise; establishes noise floor for low-light measurements; verify by capping photodiode and measuring output voltage (should be less than 10 mV for 10 MΩ feedback resistor).
- **Saturation signature:** Output voltage rails to supply limit when illumination exceeds photodiode photocurrent capacity (typically 1 mA maximum); recovery time after removing overload ranges from 100 µs to 10 ms depending on junction capacitance.
- **Spectral response:** Silicon photodiodes exhibit responsivity increasing from 0.2 A/W at 400 nm (violet) to peak 0.6 A/W at 850 nm (near-infrared), then declining to zero at 1100 nm bandgap cutoff; verify spectral match between calibration source and application lighting.
- **Linearity:** Output should be proportional to incident power within ±1% across four decades of illumination range; nonlinearity exceeding ±5% indicates transimpedance amplifier saturation or photodiode operating beyond linear region.

**Strain Gauge Load Cell Interfaces**

- **Preferred topology:** Wheatstone bridge with active strain gauge plus dummy gauge for temperature compensation; precision voltage reference excitation (5.000 V typical); instrumentation amplifier with gain 1000 for bridge output amplification.
- **Gauge factor:** 2.0 to 2.2 for constantan and karma alloy foils; represents fractional resistance change per unit strain: `ΔR/R = GF * ε`.
- **Bridge balance:** Zero output voltage at zero applied load; adjust null potentiometer to achieve balance within ±0.1 mV before applying calibration loads.
- **Sensitivity:** Typically 1 mV/V to 3 mV/V full-scale output for industrial load cells (i.e., 5 mV to 15 mV output for 5 V excitation at rated capacity).
- **Hysteresis:** Maximum separation between loading and unloading curves; should be below 0.1% full-scale output for well-constructed load cells with properly cured adhesive bonds.
- **Creep:** Time-dependent output change under constant load; specified as percent full-scale output per logarithmic decade of time; typical value 0.02% to 0.05% FSO per decade for metallic strain gauges.
- **Overload damage signature:** Permanent zero shift exceeding 0.5% FSO after removing overload indicates plastic deformation or bond failure; load cell requires recalibration or replacement.
- **Temperature compensation:** Dummy gauge should be located on same substrate as active gauge but oriented perpendicular to strain axis and shielded from applied stress; temperature drift below 0.01% FSO/°C indicates proper compensation.

**Common Analog Front-End Faults Across All Sensor Modalities**

- **ADC saturation:** Reading stuck at 0x000 or 0xFFF (for 12-bit ADC) indicates sensor signal exceeds ADC input range; reduce analog gain or add input protection clamping diodes.
- **Quantization noise dominance:** Excessive digital jitter on low-amplitude signals indicates insufficient analog gain before ADC; increase instrumentation amplifier gain or implement ADC oversampling.
- **50/60 Hz interference:** Sinusoidal modulation at power-line frequency indicates inadequate shielding, ground loop coupling, or sensor cable running parallel to AC mains; implement twisted-pair cables, star grounding, and power-line synchronous filtering.
- **Reference voltage drift:** Gradual output change correlated with ambient temperature indicates unstable voltage reference; substitute precision voltage reference IC with temperature coefficient below 10 ppm/°C.
- **Supply voltage ripple:** High-frequency noise correlated with switching power supply operation indicates inadequate power supply decoupling; add ceramic capacitors (0.1 µF) and tantalum capacitors (10 µF) at each IC power pin; use linear regulators for analog supply rails.

**Firmware-Level Diagnostic Telemetry**

Embed the following diagnostic data in sensor output packets to enable remote fault diagnosis without requiring oscilloscope access:

- Raw ADC counts in addition to calibrated engineering units to permit post-deployment gain and offset recalibration.
- Supply voltage measured via ADC ratiometric input to detect brownout conditions and reference voltage drift.
- On-chip temperature sensor reading to enable temperature-dependent drift compensation and thermal fault detection.
- Sample timestamp or sequence number to detect dropped packets, data acquisition timing jitter, or buffer overflow.
- Range indicator or gain setting for automatic-ranging interfaces to reconstruct absolute sensor values across range transitions.
- Error flags indicating out-of-range inputs, ADC saturation, sensor open/short faults, and calibration coefficient checksum failures.
- Noise floor estimate computed as standard deviation over sliding 100-sample window to detect EMI transients and shield degradation.

This diagnostic telemetry framework transforms sensor interfaces from opaque black boxes into instrumented measurement channels amenable to quantitative failure mode analysis, enabling predictive maintenance strategies that replace failing sensors before catastrophic faults disrupt system operation.
