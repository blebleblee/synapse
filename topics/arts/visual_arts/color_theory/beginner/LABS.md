# Beginner Hands-On Lab: Color Theory
## Objective & Prerequisites
The objective of this hands-on lab is to introduce beginners to the fundamental concepts of color theory through practical, hands-on exercises. This lab assumes no prior knowledge of color theory or digital art tools. We will be using a simple digital art software called GIMP, which is free and open-source. Ensure that GIMP is installed on your computer before proceeding with the lab.

## Exercise 1: Environment Setup & Sanity Check (Exact commands to verify tools)
Before we begin, let's verify that GIMP is correctly installed on your system. Follow these steps:

1. **Open GIMP:**
   - On Windows, search for "GIMP" in the Start menu and click on the application.
   - On macOS, open the Applications folder and double-click on GIMP.
   - On Linux, open a terminal and type `gimp` and press Enter.

2. **Check GIMP Version:**
   - Once GIMP opens, go to `Edit` > `Preferences`.
   - In the Preferences window, navigate to `Folders` > `Plug-ins` to ensure that the path is correctly set.
   - Close the Preferences window.

3. **Create a New Image:**
   - Go to `File` > `New`.
   - Set the image size to 800x600 pixels, and the color mode to RGB.
   - Click `OK` to create the new image.

## Exercise 2: Your First Working Experiment (Step-by-step guided instructions with expected outputs)
In this exercise, we will create a simple color wheel to understand the basic relationships between colors.

1. **Create a New Layer:**
   - In the Layers panel, right-click and select `New Layer`.
   - Name the layer "Color Wheel" and click `OK`.

2. **Select the Ellipse Tool:**
   - In the Toolbox, select the Ellipse Tool (shortcut: `E`).

3. **Draw a Circle:**
   - Hold down the `Shift` key and draw a circle in the center of the image. This will ensure the shape is perfectly circular.

4. **Fill the Circle with a Gradient:**
   - Go to `Filters` > `Render` > `Gradient`.
   - In the Gradient dialog, select the "Conic Gradient" type.
   - Choose a gradient preset that represents a color wheel, such as "Rainbow" or "Spectral".
   - Click `OK` to apply the gradient.

5. **Expected Output:**
   - You should see a circular color wheel in the center of your image, displaying a spectrum of colors transitioning smoothly from one to another.

## Exercise 3: Inspecting Basic State (Reading logs or simple outputs)
In this exercise, we will inspect the color values of specific points on the color wheel.

1. **Select the Color Picker Tool:**
   - In the Toolbox, select the Color Picker Tool (shortcut: `O`).

2. **Sample Colors:**
   - Click on different points on the color wheel to sample colors.
   - The color values will be displayed in the Color Picker dialog.

3. **Note the RGB Values:**
   - Write down the RGB values for at least three different colors on the color wheel. For example:
     - Red: (255, 0, 0)
     - Green: (0, 255, 0)
     - Blue: (0, 0, 255)

## Challenge Exercise (Simple self-test for beginners)
Create a new image and draw a simple scene using the colors from your color wheel. For example, you could draw a landscape with a red sun, green trees, and blue sky. Use the Color Picker Tool to ensure you are using the exact colors from your color wheel.

1. **Create a New Image:**
   - Go to `File` > `New`.
   - Set the image size to 800x600 pixels, and the color mode to RGB.
   - Click `OK` to create the new image.

2. **Draw Your Scene:**
   - Use the Brush Tool (shortcut: `B`) to draw your scene.
   - Use the Color Picker Tool to sample colors from your color wheel and apply them to your scene.

3. **Save Your Work:**
   - Go to `File` > `Export As`.
   - Choose a file format (e.g., PNG) and save your image.

By completing this lab, you should have a basic understanding of how to use GIMP to explore color theory and create simple digital art.
