# Beginner Hands-On Lab: Piano
## Objective & Prerequisites
### Objective
In this lab, you'll set up your environment for piano practice and execute basic commands to ensure everything is working as expected.

### Prerequisites
- Install a digital audio workstation (DAW) or a piano learning software on your computer (e.g., MuseScore, Piano Maestro, or Yousician).
- Familiarize yourself with the software's interface.
- Have a keyboard or piano connected to your computer (if using a DAW).

## Exercise 1: Environment Setup & Sanity Check
### Step 1: Launch Your DAW/Software
Open your chosen software. If you're using a DAW, ensure it's connected to your keyboard or piano.

### Step 2: Verify Tools
- **For DAW Users:**
  - Check if your keyboard or piano is recognized by the software.
  - Ensure the software is set to the correct input and output settings.
- **For Software Users:**
  - Check if the software is properly connected to your keyboard or piano (if applicable).
  - Verify that the software's interface is clear and understandable.

### Step 3: Sanity Check Commands
- **For DAW Users:**
  - Open a new project or song.
  - Press a key on your keyboard or piano. The software should register the note.
- **For Software Users:**
  - Open a new lesson or exercise.
  - Press a key on your keyboard or piano. The software should register the note.

## Exercise 2: Your First Working Experiment
### Step 1: Create a New Project
- Open your DAW or software and create a new project or song.

### Step 2: Set Up Your Instrument
- If using a DAW, ensure your keyboard or piano is set as the input device.
- If using software, ensure it's set to the correct input settings.

### Step 3: Play a Note
- Press a key on your keyboard or piano. The software should register the note and display it on the screen.

### Step 4: Experiment with Different Notes
- Press different keys on your keyboard or piano to see how the software responds.

## Exercise 3: Inspecting Basic State
### Step 1: Review Your Project
- Take a moment to review your project or song. Ensure everything is set up correctly.

### Step 2: Check the Logs
- If using a DAW, check the software's logs to ensure there are no errors.

### Step 3: Verify Settings
- Double-check your settings to ensure everything is correct.

## Challenge Exercise
### Step 1: Play a Simple Melody
- Using the software, play a simple melody (e.g., "Twinkle, Twinkle, Little Star").

### Step 2: Record Yourself
- Record yourself playing the melody.

### Step 3: Analyze Your Performance
- Listen back to your recording and analyze your performance.

### Step 4: Repeat and Improve
- Repeat the exercise, focusing on improving your performance.

By completing these exercises, you'll have a solid foundation for your piano practice and be ready to move on to more advanced topics.
