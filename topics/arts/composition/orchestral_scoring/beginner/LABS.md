# Beginner Hands-On Lab: Orchestral Scoring

## Objective & Prerequisites
The objective of this lab is to introduce you to the basic environment and tools necessary for orchestral scoring. This will include setting up a digital audio workstation (DAW) and using a notation software like MuseScore or Sibelius. By the end of this lab, you should be able to create a simple orchestral score and understand the basic layout and functionality of the software.

### Prerequisites
- A computer with a DAW installed (e.g., MuseScore, Sibelius, Finale).
- Basic understanding of music theory (scales, chords, and basic orchestration).

## Exercise 1: Environment Setup & Sanity Check (Exact commands to verify tools)
### Step 1: Install MuseScore
1. Download MuseScore from the official website: [MuseScore Download](https://musescore.org/en/download).
2. Follow the installation instructions for your operating system.

### Step 2: Verify Installation
1. Open MuseScore.
2. Ensure that the application launches without any errors and that the interface is displayed correctly.

## Exercise 2: Your First Working Experiment (Step-by-step guided instructions with expected outputs)
### Step 1: Create a New Score
1. Open MuseScore.
2. Click on `File` > `New` to create a new score.
3. In the `Create New Score` dialog, select `Orchestra` from the list of templates.
4. Click `OK` to create the score.

### Step 2: Add a Simple Melody
1. Click on the `Piano` staff to select it.
2. Use the mouse to click on the first measure to add a note. Click and drag to change the note duration.
3. Add a simple melody using the notes C, D, E, F, G, A, B, and C (C major scale).
4. Ensure that the notes are correctly placed and that the rhythm is consistent.

### Step 3: Add Orchestral Instruments
1. Click on the `Add Instruments` button (a green plus sign) in the toolbar.
2. In the `Add Instruments` dialog, select the `Strings` section.
3. Add the following instruments: Violin I, Violin II, Viola, Cello, and Double Bass.
4. Click `OK` to add the instruments to the score.

### Step 4: Assign the Melody to Different Instruments
1. Select the notes in the `Piano` staff.
2. Copy the notes by pressing `Ctrl+C` (or `Cmd+C` on Mac).
3. Click on the `Violin I` staff and paste the notes by pressing `Ctrl+V` (or `Cmd+V` on Mac).
4. Repeat the process for `Violin II`, `Viola`, `Cello`, and `Double Bass`.

### Expected Output
You should have a simple C major scale melody distributed across the five string instruments of the orchestra. Each instrument should have the same melody, but you can modify the notes and rhythms later to create a more complex orchestral arrangement.

## Exercise 3: Inspecting Basic State (Reading logs or simple outputs)
### Step 1: Save Your Score
1. Click on `File` > `Save As`.
2. Choose a location to save your file and name it `OrchestralScoringLab.mscz`.
3. Click `Save` to save your score.

### Step 2: Preview Your Score
1. Click on `View` > `Play` to preview your score.
2. Listen to the playback and ensure that the melody is correctly played by all the instruments.
3. If there are any issues, go back to the score and make the necessary corrections.

## Challenge Exercise (Simple self-test for beginners)
### Task
Modify the simple C major scale melody you created in Exercise 2 to include a simple harmonic progression. Use the following chords: C major, G major, Am minor, and F major. Ensure that the melody fits the harmony and that each instrument has a distinct part.

### Steps
1. Add a new staff for the `Piano` if it was removed.
2. Create a simple harmonic progression using the chords C major, G major, Am minor, and F major.
3. Modify the melody to fit the harmonic progression.
4. Distribute the melody and chords across the five string instruments.
5. Save your modified score as `OrchestralScoringLab_Modified.mscz`.
6. Preview your modified score to ensure that the melody and harmony are correctly played by all the instruments.

### Expected Output
You should have a simple orchestral arrangement with a C major scale melody that fits a harmonic progression of C major, G major, Am minor, and F major. Each instrument should have a distinct part, and the overall arrangement should sound harmonious and balanced.
