# Beginner Hands-On Lab: Orchestration
## Objective & Prerequisites

### Objective
The objective of this hands-on lab is to introduce you to the foundational tools and environment necessary for orchestration. By the end of this lab, you will have set up your orchestration environment, executed your first commands, and inspected basic state outputs.

### Prerequisites
- Basic familiarity with a computer operating system (Windows, macOS, or Linux).
- Access to a digital audio workstation (DAW) such as Ableton Live, Logic Pro, or FL Studio.
- Basic understanding of musical notation and orchestral instruments.

## Exercise 1: Environment Setup & Sanity Check (Exact commands to verify tools)

### Step 1: Install a Digital Audio Workstation (DAW)
If you do not already have a DAW installed, download and install one of the following:
- **Ableton Live**: [Download Link](https://www.ableton.com/en/live/)
- **Logic Pro**: [Download Link](https://www.apple.com/logic-pro/)
- **FL Studio**: [Download Link](https://www.image-line.com/flstudio/)

### Step 2: Verify DAW Installation
Launch your chosen DAW and ensure it opens without any errors. Check the version number in the "About" section to confirm the installation.

### Step 3: Install Orchestral Sample Libraries
Most DAWs come with a basic set of orchestral samples, but you may want to install additional libraries for more comprehensive orchestration. Some popular orchestral sample libraries include:
- **EastWest Symphonic Orchestra**
- **Garritan Personal Orchestra**
- **Kontakt (with orchestral libraries)**

For this lab, we will use the default orchestral samples provided by your DAW.

## Exercise 2: Your First Working Experiment (Step-by-step guided instructions with expected outputs)

### Step 1: Create a New Project
1. Open your DAW.
2. Create a new project by selecting `File > New Project` or using the shortcut (usually `Ctrl+N` or `Cmd+N`).

### Step 2: Add an Orchestral Instrument
1. Add a new track by selecting `Track > Insert Track` or using the shortcut (usually `Ctrl+T` or `Cmd+T`).
2. Rename the track to "Violin".
3. Select the orchestral sample library for the Violin. This can usually be done by selecting the instrument from the instrument browser or by loading a preset.

### Step 3: Input a Simple Melody
1. Enter MIDI note input mode by selecting `Edit > MIDI > Note Input` or using the shortcut (usually `Ctrl+M` or `Cmd+M`).
2. Input a simple C major scale (C4, D4, E4, F4, G4, A4, B4, C5) on the Violin track. You can do this by clicking on the piano roll and entering notes or by playing the notes on a MIDI keyboard.

### Step 4: Play the Melody
1. Press the play button (usually a triangle icon) to play the melody.
2. You should hear a simple C major scale played by the Violin sample.

## Exercise 3: Inspecting Basic State (Reading logs or simple outputs)

### Step 1: View the Piano Roll
1. Ensure the piano roll is visible for the Violin track.
2. Observe the notes you entered. They should be displayed as vertical lines on the piano roll, corresponding to the C major scale.

### Step 2: Check the Instrument Settings
1. Open the instrument settings for the Violin track.
2. Verify that the correct orchestral sample library is selected and that the settings are appropriate for the Violin.

## Challenge Exercise (Simple self-test for beginners)

### Task
Add a second track with a Cello and input a simple C major scale (C2, D2, E2, F2, G2, A2, B2, C3) that plays in harmony with the Violin track.

### Instructions
1. Add a new track and rename it "Cello".
2. Select the orchestral sample library for the Cello.
3. Input the C major scale on the Cello track, starting from C2.
4. Play the project and ensure both the Violin and Cello play in harmony.

### Expected Output
You should hear a simple C major scale played by both the Violin and Cello, creating a harmonious duet.
