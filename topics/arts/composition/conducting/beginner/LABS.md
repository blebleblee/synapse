# Beginner Hands-On Lab: Conducting
## Objective & Prerequisites

### Objective
The objective of this hands-on lab is to introduce beginners to the foundational concepts of conducting through practical, interactive exercises. By the end of this lab, you will have set up a basic conducting environment, executed your first conducting commands, and inspected the basic state of your conducting setup.

### Prerequisites
- Basic understanding of music theory and rhythm.
- Access to a computer with internet connectivity.
- Installation of a digital audio workstation (DAW) such as Ableton Live, Logic Pro, or FL Studio.
- A basic understanding of how to navigate your chosen DAW.

## Exercise 1: Environment Setup & Sanity Check (Exact commands to verify tools)

### Step 1: Install a DAW
If you haven't already installed a DAW, download and install one of the following:
- **Ableton Live**: [Download Link](https://www.ableton.com/en/live/)
- **Logic Pro**: [Download Link](https://www.apple.com/logic-pro/)
- **FL Studio**: [Download Link](https://www.image-line.com/flstudio/)

### Step 2: Verify Installation
Open your DAW and ensure it launches without errors. Perform a simple sanity check by creating a new project and adding a basic instrument track.

#### For Ableton Live:
1. Open Ableton Live.
2. Click on `File` > `New` to create a new project.
3. Click on `Add Instrument` and select `Analog` (or any other instrument).
4. Play a note on the piano roll or MIDI keyboard to verify sound output.

#### For Logic Pro:
1. Open Logic Pro.
2. Click on `File` > `New` to create a new project.
3. Click on `Tracks` > `Software Instrument` to add an instrument track.
4. Play a note on the piano roll or MIDI keyboard to verify sound output.

#### For FL Studio:
1. Open FL Studio.
2. Click on `File` > `New` to create a new project.
3. Click on `Add New Channel` and select `Instrument`.
4. Play a note on the piano roll or MIDI keyboard to verify sound output.

## Exercise 2: Your First Working Experiment (Step-by-step guided instructions with expected outputs)

### Step 1: Create a Simple Beat
1. In your DAW, create a new project.
2. Add a drum machine or drum kit instrument.
3. Program a simple 4/4 beat with kick, snare, and hi-hat.

#### Example for Ableton Live:
1. Click on `Add Instrument` and select `Drum Rack`.
2. Click on the `Kick` pad and select a kick sample.
3. Click on the `Snare` pad and select a snare sample.
4. Click on the `Hi-Hat` pad and select a hi-hat sample.
5. In the `Session View`, click on the `Drum Rack` and program the following pattern:
   - Kick: [X---] (Kick on beat 1)
   - Snare: [--X-] (Snare on beat 3)
   - Hi-Hat: [X-X-X-X] (Hi-hat on every beat)

#### Example for Logic Pro:
1. Click on `Tracks` > `Software Instrument` and select a drum kit.
2. In the `Piano Roll`, program the following pattern:
   - Kick: [X---] (Kick on beat 1)
   - Snare: [--X-] (Snare on beat 3)
   - Hi-Hat: [X-X-X-X] (Hi-hat on every beat)

#### Example for FL Studio:
1. Click on `Add New Channel` and select `Drum Machine`.
2. In the `Piano Roll`, program the following pattern:
   - Kick: [X---] (Kick on beat 1)
   - Snare: [--X-] (Snare on beat 3)
   - Hi-Hat: [X-X-X-X] (Hi-hat on every beat)

### Step 2: Add a Conductor Track
1. Add a new MIDI track for conducting.
2. Program a simple conducting pattern using MIDI notes to represent conducting gestures.

#### Example for Ableton Live:
1. Click on `Add Track` and select `MIDI`.
2. Rename the track to `Conductor`.
3. In the `Session View`, click on the `Conductor` track and program the following pattern:
   - Conducting Gesture: [X-X-X-X] (Conducting gesture on every beat)

#### Example for Logic Pro:
1. Click on `Tracks` > `MIDI` to add a new MIDI track.
2. Rename the track to `Conductor`.
3. In the `Piano Roll`, program the following pattern:
   - Conducting Gesture: [X-X-X-X] (Conducting gesture on every beat)

#### Example for FL Studio:
1. Click on `Add New Channel` and select `MIDI`.
2. Rename the channel to `Conductor`.
3. In the `Piano Roll`, program the following pattern:
   - Conducting Gesture: [X-X-X-X] (Conducting gesture on every beat)

### Expected Output
You should hear a simple 4/4 beat with kick, snare, and hi-hat, and see a conducting gesture pattern programmed on the `Conductor` track.

## Exercise 3: Inspecting Basic State (Reading logs or simple outputs)

### Step 1: Inspect the Beat
1. Play the beat and inspect the output in the `Arrangement View` or `Session View`.
2. Ensure that the kick, snare, and hi-hat are playing in time with the beat.

### Step 2: Inspect the Conductor Track
1. Play the beat and inspect the `Conductor` track.
2. Ensure that the conducting gesture pattern is synchronized with the beat.

### Expected Output
You should see the kick, snare, and hi-hat playing in time with the beat, and the conducting gesture pattern should be synchronized with the beat.

## Challenge Exercise (Simple self-test for beginners)

### Challenge
Create a simple 3/4 waltz beat with a different drum kit and program a conducting gesture pattern that matches the waltz rhythm.

### Steps:
1. Add a new drum kit instrument.
2. Program a simple 3/4 waltz beat with kick, snare, and hi-hat.
3. Program a conducting gesture pattern that matches the waltz rhythm.

### Expected Output
You should hear a simple 3/4 waltz beat with kick, snare, and hi-hat, and see a conducting gesture pattern that matches the waltz rhythm.
