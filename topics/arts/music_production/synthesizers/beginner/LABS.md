# Beginner Hands-On Lab: Synthesizers
## Objective & Prerequisites
### Objective
The objective of this lab is to familiarize beginners with the basic setup and operation of a synthesizer using a software-based synthesizer application. By the end of this lab, you should be able to set up your environment, create a simple sound, and inspect the basic state of your synthesizer.

### Prerequisites
- A computer with an internet connection.
- Basic understanding of music theory (optional but recommended).
- Software synthesizer application installed (e.g., VST, AU, or standalone software like Ableton Live, FL Studio, or a free alternative like LMMS).

## Exercise 1: Environment Setup & Sanity Check
### Instructions
1. **Install a Software Synthesizer:**
   - Download and install a software synthesizer of your choice. For this lab, we will use LMMS (Linux Multimedia Studio), which is free and open-source.
   - **Download LMMS:** Visit the [LMMS website](https://lmms.io/) and download the installer for your operating system.
   - **Install LMMS:** Follow the installation instructions provided on the website.

2. **Launch LMMS:**
   - Open LMMS from your applications menu or desktop shortcut.
   - Ensure that LMMS launches without any errors.

### Expected Output
- LMMS should open without any errors, displaying its main interface.

## Exercise 2: Your First Working Experiment
### Instructions
1. **Create a New Project:**
   - Click on `File` in the top menu and select `New` to create a new project.

2. **Add a Synth Instrument:**
   - Click on the `Instruments` tab on the left side of the interface.
   - Click on the `+` button to add a new instrument.
   - Select `ZynAddSubFX` (or any other synthesizer available) from the list of available instruments.

3. **Play a Note:**
   - Click on the `Piano Roll` tab to open the piano roll editor.
   - Click on the grid to add a note. You can choose any note and duration.
   - Click the `Play` button at the bottom of the interface to hear the sound.

### Expected Output
- You should hear a synthesized sound corresponding to the note you played.

## Exercise 3: Inspecting Basic State
### Instructions
1. **View Instrument Settings:**
   - Click on the `Instruments` tab to view the settings of the synthesizer you added.
   - Explore the various tabs and parameters available in the synthesizer settings.

2. **Check the Piano Roll:**
   - Click on the `Piano Roll` tab to view the notes you added.
   - Ensure that the notes are displayed correctly and that you can modify them by clicking and dragging.

### Expected Output
- You should be able to view and modify the settings of the synthesizer and see the notes in the piano roll.

## Challenge Exercise (Simple self-test for beginners)
### Instructions
1. **Create a Simple Melody:**
   - Using the piano roll, create a simple melody by adding a series of notes.
   - Experiment with different notes and durations to create a short tune.

2. **Play the Melody:**
   - Click the `Play` button to hear your melody.
   - Make adjustments to the notes and settings as needed to improve the sound.

### Expected Output
- You should be able to create and play a simple melody using the synthesizer.

By completing this lab, you should have a basic understanding of how to set up and use a software synthesizer. Feel free to explore further and experiment with different settings and sounds!
