# Beginner Hands-On Lab: Audio Plugins
## Objective & Prerequisites
### Objective
This lab aims to introduce you to the basics of using audio plugins in a Digital Audio Workstation (DAW) environment. By the end of this lab, you will have set up your environment, loaded your first plugin, and performed a simple experiment to verify everything is working correctly.

### Prerequisites
- A DAW installed on your computer (e.g., Ableton Live, FL Studio, Logic Pro, etc.).
- Basic understanding of how to navigate your DAW.
- Basic understanding of audio terminology (e.g., track, plugin, effect).

## Exercise 1: Environment Setup & Sanity Check
### Step-by-Step Instructions
1. **Open your DAW.**
2. **Create a new project.**
3. **Add an audio track:**
   - In Ableton Live: Right-click on the session view and select `Create Audio Track`.
   - In FL Studio: Click on the `Channels` tab and click the `+` button to add a new channel.
   - In Logic Pro: Click on `Track` in the menu bar, then `New Track`, and select `Audio`.
4. **Verify the track is created:**
   - Ensure the track appears in the session or arrangement view.
   - Check that the track has an input and output assigned.

### Expected Output
- A new audio track should appear in your DAW with an input and output assigned.

## Exercise 2: Your First Working Experiment
### Step-by-Step Instructions
1. **Load an audio plugin:**
   - In Ableton Live: Right-click on the audio track, select `Add Effect`, and choose any effect from the list.
   - In FL Studio: Click on the channel you created, then click on the `FX` tab, and choose any effect from the list.
   - In Logic Pro: Click on the audio track, then click on the `Insert` button, and choose any effect from the list.
2. **Adjust a parameter on the plugin:**
   - Find a parameter that you can easily adjust (e.g., gain, reverb mix).
   - Change the value of the parameter to see the effect on the audio.
3. **Play a sound through the track:**
   - Ensure you have an audio clip or MIDI clip loaded and routed to the track.
   - Play the clip and listen to the effect of the plugin.

### Expected Output
- You should hear the audio clip with the effect of the plugin applied.

## Exercise 3: Inspecting Basic State
### Step-by-Step Instructions
1. **Check the plugin settings:**
   - Look at the parameters you adjusted in the plugin.
   - Verify that the values are set to what you changed them to.
2. **Check the DAW's log or output:**
   - Some DAWs have a log or output window that shows messages or errors.
   - Check this window to ensure there are no error messages related to the plugin.

### Expected Output
- The plugin settings should reflect the changes you made.
- The DAW's log or output should not show any error messages related to the plugin.

## Challenge Exercise
### Step-by-Step Instructions
1. **Try loading a different type of plugin:**
   - Load an instrument plugin (e.g., synthesizer, sampler) instead of an effect plugin.
   - Play a note or chord using the instrument plugin.
2. **Adjust a parameter on the instrument plugin:**
   - Find a parameter that you can easily adjust (e.g., filter cutoff, oscillator waveform).
   - Change the value of the parameter to see the effect on the sound.
3. **Record a short clip using the instrument plugin:**
   - Arm the track for recording.
   - Play a short sequence of notes or chords.
   - Stop recording and listen to the recorded clip.

### Expected Output
- You should hear the sound of the instrument plugin with the effect of the parameter adjustment.
- The recorded clip should reflect the sound of the instrument plugin.
