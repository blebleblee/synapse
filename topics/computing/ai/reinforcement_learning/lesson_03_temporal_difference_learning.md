# Lesson 3: TD Learning, Q-Learning, SARSA, Function Approximation

## 1. First-Principles Intuition & Invariants

The central challenge in reinforcement learning emerges from a fundamental tension: an agent must learn the value of actions in states by taking those actions and observing outcomes, yet the value of any single state-action pair depends on the values of future states that have not yet been accurately estimated. Dynamic programming methods resolved this circular dependency by assuming perfect knowledge of the environment's transition dynamics, enabling synchronous value propagation across the entire state space through Bellman backup operations. Temporal-difference learning shatters this requirement by learning directly from experience trajectories, bootstrapping value estimates from other value estimates in a continuous process of iterative refinement.

The core insight underlying TD learning rests on a simple but profound observation: when an agent transitions from state $s$ to state $s'$ and receives reward $r$, it can immediately compute a *better* estimate of $V(s)$ by combining the observed reward with its current estimate of $V(s')$. This TD target $r + \gamma V(s')$ provides a sample-based approximation of the Bellman expectation without requiring explicit knowledge of transition probabilities or reward distributions. The temporal-difference error $\delta_t = r + \gamma V(s') - V(s)$ quantifies the discrepancy between the agent's prediction and the empirical outcome, driving incremental updates that gradually align value estimates with realized returns.

This learning signal possesses several critical properties that distinguish it from Monte Carlo methods. First, TD learning is *online and incremental*—it updates value estimates after every time step rather than waiting for episode termination, enabling continuous learning in both episodic and continuing tasks. Second, TD methods exhibit lower variance than Monte Carlo approaches because they bootstrap from existing value estimates rather than sampling complete return trajectories, which can vary dramatically across episodes. Third, TD learning naturally exploits the Markov property of the state representation: if the current state captures all relevant information about future outcomes, then bootstrapping from $V(s')$ is theoretically sound because $s'$ itself encodes the conditional distribution over future returns.

The theoretical foundation of TD learning emerges from stochastic approximation theory, specifically the Robbins-Monro algorithm for finding roots of expected values. When the learning rate $\alpha_t$ satisfies the conditions $\sum_{t=1}^{\infty} \alpha_t = \infty$ and $\sum_{t=1}^{\infty} \alpha_t^2 < \infty$, TD updates converge almost surely to the true value function under tabular representation and on-policy sampling. This convergence guarantee extends to certain classes of function approximation but critically fails for off-policy learning with nonlinear approximators, a stability boundary that has driven decades of algorithmic innovation.

When we extend value learning from states to state-action pairs, we arrive at the foundational algorithms for optimal control: Q-learning and SARSA. Both methods maintain estimates $Q(s,a)$ of the expected return from taking action $a$ in state $s$ and following some policy thereafter. The distinction between them lies in how they construct the TD target. SARSA, an acronym for State-Action-Reward-State-Action, uses the actual action $a'$ selected by the behavior policy in state $s'$, making it an *on-policy* algorithm that learns the value of the policy it is currently executing. Q-learning instead uses the maximum Q-value over all actions in $s'$, bootstrapping from the greedy action regardless of what action was actually taken, making it an *off-policy* algorithm that learns the optimal policy even while following an exploratory behavior policy.

This seemingly minor distinction carries profound implications for convergence, sample efficiency, and safety. On-policy methods like SARSA converge to the optimal policy only when exploration eventually ceases, but they learn a conservative policy that accounts for exploration in their value estimates. Off-policy methods like Q-learning separate the policy being learned (the target policy) from the policy generating experience (the behavior policy), enabling aggressive exploration while learning optimal greedy behavior. However, this separation introduces distributional shift between the data-generating process and the target value function, creating instability when combined with function approximation—a phenomenon known as the *deadly triad* of bootstrapping, function approximation, and off-policy learning.

The exploration-exploitation tradeoff manifests as a fundamental constraint on sample efficiency. Pure exploitation—always selecting the action with highest estimated value—risks convergence to suboptimal policies when value estimates are inaccurate early in training. Pure exploration wastes samples on actions that are demonstrably inferior. Epsilon-greedy policies provide a simple stochastic solution: with probability $\epsilon$ select a random action, otherwise select greedily. This maintains a constant exploration rate but cannot adapt as value estimates improve. Upper Confidence Bound (UCB) methods resolve this by maintaining uncertainty estimates and selecting actions that maximize $Q(s,a) + c\sqrt{\frac{\ln t}{N(s,a)}}$, balancing exploitation of high-value actions with exploration of uncertain actions. The logarithmic growth of the exploration bonus ensures that all actions are tried infinitely often but increasingly rarely as evidence accumulates.

The transition from tabular to function-approximated value estimation represents both an engineering necessity and a theoretical minefield. Real-world state spaces—continuous control tasks, image observations, combinatorial optimization problems—render tabular representations computationally infeasible. Function approximation addresses this by parameterizing the value function as $\hat{V}(s; \mathbf{w})$ or $\hat{Q}(s,a; \mathbf{w})$ where $\mathbf{w}$ denotes a parameter vector updated via gradient descent on the TD error. Linear function approximation, where $\hat{V}(s; \mathbf{w}) = \mathbf{w}^T \phi(s)$ for feature vector $\phi(s)$, preserves convergence guarantees for on-policy TD learning and Q-learning under specific conditions. Nonlinear approximators like neural networks introduce representational power sufficient for complex tasks but violate the contractiveness assumptions underlying tabular convergence proofs, leading to potential divergence, instability, and catastrophic forgetting.

The TD error $\delta_t = r + \gamma \hat{Q}(s', \arg\max_{a'} \hat{Q}(s',a'; \mathbf{w}); \mathbf{w}) - \hat{Q}(s,a; \mathbf{w})$ in Q-learning suffers from *maximization bias*: using the same value estimates to both select and evaluate actions systematically overestimates values because the maximum of noisy estimates is biased upward. Double Q-learning addresses this by maintaining two independent value estimates $\mathbf{w}_1$ and $\mathbf{w}_2$, using one to select the best action and the other to estimate its value. This decorrelates the selection and evaluation steps, significantly reducing bias in environments with stochastic rewards.

Experience replay, introduced to stabilize neural network training in DQN, breaks the temporal correlation inherent in sequential experience by storing transitions $(s,a,r,s')$ in a replay buffer and sampling random minibatches for gradient updates. This simple technique transforms online RL into a supervised learning regime where the targets themselves evolve as the network improves, but it introduces off-policy learning even for on-policy algorithms and requires careful handling of priorities—more important transitions should be sampled more frequently, leading to prioritized experience replay that weights samples by their TD error magnitude.

The convergence guarantees, failure modes, and practical performance of TD methods rest on a delicate interplay between the Bellman operator's contractiveness, the expressiveness of the function class, the distribution over states induced by the behavior policy, and the step-size schedule. Understanding these interactions enables practitioners to diagnose instability, design appropriate architectures, and select algorithmic components that align with their deployment constraints.

## 2. Core Architecture & Mechanics

The TD(0) algorithm for state-value estimation establishes the foundational update mechanism from which all temporal-difference methods derive. Upon observing a transition from state $s_t$ to state $s_{t+1}$ with reward $r_{t+1}$, the agent computes the TD error $\delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t)$ and updates the value estimate via $V(s_t) \leftarrow V(s_t) + \alpha \delta_t$. This single-step update bootstraps from the immediate successor state, contrasting with Monte Carlo methods that wait for the full return $G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}$ before updating. The discount factor $\gamma \in [0,1)$ controls the time horizon of the value estimate: $\gamma$ near zero produces myopic policies sensitive only to immediate rewards, while $\gamma$ approaching one incorporates distant future rewards at the cost of slower convergence and higher variance.

The TD($\lambda$) algorithm generalizes this single-step update by blending bootstrapping at multiple time horizons through eligibility traces. Rather than updating only the immediately preceding state, TD($\lambda$) maintains an eligibility trace $e_t(s)$ for each state that accumulates evidence of recent visits according to $e_t(s) = \gamma \lambda e_{t-1}(s) + \mathbb{1}[s_t = s]$. The update rule then becomes $V(s) \leftarrow V(s) + \alpha \delta_t e_t(s)$ for all states, distributing credit to states that contributed to the current transition. When $\lambda = 0$, this reduces to TD(0); when $\lambda = 1$, it approximates Monte Carlo updates. The trace decay parameter $\lambda$ thus interpolates between the low-variance, high-bias regime of single-step bootstrapping and the high-variance, low-bias regime of full trajectory returns.

SARSA, the fundamental on-policy control algorithm, extends TD learning to action-value functions by sampling the quintuple $(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1})$ where both actions are selected according to the current behavior policy $\pi$. The update rule mirrors TD(0) but operates on $Q$ values:

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha [r_{t+1} + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t)]$$

This on-policy structure ensures that value estimates reflect the expected return under the policy actually being executed, including the effects of exploration. When using an epsilon-greedy policy, SARSA learns conservative behavior near cliffs or dangerous states because it anticipates occasional random actions. The algorithm converges to the optimal policy for the Markov Decision Process only if the exploration rate decays to zero, typically using a schedule like $\epsilon_t = \max(\epsilon_{min}, \epsilon_0 / t)$.

Q-learning introduces a critical architectural departure by decoupling the behavior policy from the target policy. The update rule replaces the next action value with the maximum:

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha [r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t)]$$

This off-policy target learns the value of the greedy policy regardless of which action was actually selected in $s_{t+1}$. The algorithmic flow proceeds as follows: the agent selects action $a_t$ according to an exploration policy (often epsilon-greedy), observes reward $r_{t+1}$ and next state $s_{t+1}$, computes the TD target using the max operator, and updates $Q(s_t, a_t)$ accordingly. The next action $a_{t+1}$ selected for execution may differ from the greedy action used in the target computation, creating the off-policy behavior.

The convergence proof for Q-learning relies on the Bellman optimality operator $\mathcal{T}^*$ being a contraction mapping in the supremum norm when applied to tabular Q-functions. The update can be interpreted as a stochastic approximation to the fixed-point iteration $Q \leftarrow \mathcal{T}^* Q$ where $(\mathcal{T}^* Q)(s,a) = \mathbb{E}[r + \gamma \max_{a'} Q(s',a') | s,a]$. Under tabular representation, every state-action pair visited infinitely often, and Robbins-Monro step-size conditions, Q-learning converges almost surely to $Q^*$ even when following an exploratory policy that visits all state-action pairs with non-zero probability.

Function approximation introduces a parameterized hypothesis class $\hat{Q}(s,a; \mathbf{w})$ and updates the parameters via gradient descent on the squared TD error. For linear function approximation $\hat{Q}(s,a; \mathbf{w}) = \mathbf{w}^T \phi(s,a)$ where $\phi(s,a) \in \mathbb{R}^d$ is a feature vector, the update becomes:

$$\mathbf{w} \leftarrow \mathbf{w} + \alpha [r + \gamma \max_{a'} \mathbf{w}^T \phi(s',a') - \mathbf{w}^T \phi(s,a)] \phi(s,a)$$

This semi-gradient method (so-called because it treats the target $r + \gamma \max_{a'} \mathbf{w}^T \phi(s',a')$ as constant with respect to $\mathbf{w}$) is not a true gradient descent because the target itself depends on the parameters being updated. For linear approximation under on-policy sampling, TD learning converges to a point near the optimal representable value function. For Q-learning with linear approximation, convergence depends on the feature representation and sampling distribution but is not guaranteed in general.

Deep Q-Networks (DQN) extend Q-learning to neural network function approximators by introducing two key architectural components: experience replay and target networks. The replay buffer $\mathcal{D}$ stores transitions $(s,a,r,s')$ and uniformly samples minibatches for training, breaking temporal correlation and enabling multiple gradient updates per environment step. The target network $\hat{Q}(s,a; \mathbf{w}^-)$ maintains a lagged copy of the online network parameters $\mathbf{w}$, updated periodically via $\mathbf{w}^- \leftarrow \mathbf{w}$ every $C$ steps. The loss function becomes:

$$L(\mathbf{w}) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}} [(r + \gamma \max_{a'} \hat{Q}(s',a'; \mathbf{w}^-) - \hat{Q}(s,a; \mathbf{w}))^2]$$

The target network stabilizes training by providing a slowly-changing regression target, preventing the destructive feedback loop where the network chases its own shifting predictions. Experience replay further stabilizes learning by smoothing the data distribution and allowing rare transitions to be replayed multiple times.

Double Q-learning addresses maximization bias by decoupling action selection from action evaluation. The standard implementation maintains two value functions $Q_1$ and $Q_2$, each updated using the other as the target. The update for $Q_1$ becomes:

$$Q_1(s,a) \leftarrow Q_1(s,a) + \alpha [r + \gamma Q_2(s', \arg\max_{a'} Q_1(s',a')) - Q_1(s,a)]$$

Here $Q_1$ selects the best action in $s'$, but $Q_2$ evaluates that action's value. The roles swap for updates to $Q_2$. In the deep learning context, Double DQN simplifies this by using the online network for selection and the target network for evaluation:

$$L(\mathbf{w}) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}} [(r + \gamma \hat{Q}(s', \arg\max_{a'} \hat{Q}(s',a'; \mathbf{w}); \mathbf{w}^-) - \hat{Q}(s,a; \mathbf{w}))^2]$$

This eliminates the need for a second independent network while still decorrelating the selection and evaluation steps that cause overestimation.

Expected SARSA modifies the SARSA update to compute the expectation over the policy distribution rather than sampling a single action. The update becomes:

$$Q(s,a) \leftarrow Q(s,a) + \alpha [r + \gamma \mathbb{E}_{\pi}[Q(s',a') | s'] - Q(s,a)]$$

where $\mathbb{E}_{\pi}[Q(s',a') | s'] = \sum_{a'} \pi(a'|s') Q(s',a')$. For an epsilon-greedy policy, this expectation can be computed explicitly as $\epsilon |A|^{-1} \sum_{a'} Q(s',a') + (1-\epsilon) \max_{a'} Q(s',a')$. Expected SARSA eliminates the variance introduced by sampling the next action, often improving sample efficiency while retaining the on-policy convergence guarantees.

The architectural dataflow in a complete Q-learning system with experience replay proceeds as follows:

```text
Environment Interaction Loop:
  s ← current state
  a ← ε-greedy(s; Q)
  Execute a, observe r, s'
  Store (s, a, r, s') in replay buffer D
  
  Training Loop (every N steps):
    Sample minibatch B from D
    For each (s, a, r, s') in B:
      if s' is terminal:
        y ← r
      else:
        y ← r + γ max_a' Q(s', a'; w⁻)
      Compute loss L = (y - Q(s, a; w))²
      Update w via gradient descent on L
    
    Every C steps:
      w⁻ ← w
```

The hyperparameters governing this process—replay buffer capacity, minibatch size, target network update frequency, learning rate schedule, exploration decay—must be carefully tuned to the task at hand. Small buffers limit distributional smoothing but enable faster adaptation to non-stationary environments. Large minibatches stabilize gradient estimates but reduce update frequency. Frequent target updates accelerate learning but risk instability. The practitioner must navigate these tradeoffs based on the specific dynamics of the environment and the capacity of the function approximator.

## 3. High-Performance Optimization & Failure Modes

The sample efficiency of TD learning algorithms hinges on the feature representation for function approximation. In tabular settings, no generalization occurs between states, requiring exhaustive exploration to learn accurate values. Linear function approximation enables generalization through shared features: updating $Q(s,a)$ affects $Q(s',a')$ whenever $\phi(s,a)$ and $\phi(s',a')$ have non-zero inner product. The quality of this generalization depends entirely on the feature engineering. For continuous control tasks, tile coding or radial basis functions provide manually designed representations that partition the state-action space into overlapping regions. Neural networks eliminate manual feature design but introduce training instability and hyperparameter sensitivity.

Prioritized experience replay significantly improves sample efficiency by biasing the replay distribution toward high-TD-error transitions that carry more learning signal. The priority of transition $i$ is set to $p_i = |\delta_i| + \epsilon$ where $\delta_i$ is the TD error and $\epsilon$ prevents zero probabilities. Sampling probabilities are computed via $P(i) = p_i^\alpha / \sum_j p_j^\alpha$ where $\alpha$ controls the degree of prioritization. This introduces bias because the distribution over sampled transitions no longer matches the true state distribution, requiring importance sampling corrections. The weight $w_i = (N \cdot P(i))^{-\beta}$ normalizes the gradient, with $\beta$ annealed from a small value to one over training to progressively correct the bias. The overhead of maintaining priorities and sampling efficiently can be mitigated using sum-tree data structures that enable $O(\log N)$ updates and sampling.

Rainbow DQN combines six orthogonal extensions to DQN: double Q-learning to reduce overestimation, prioritized replay for sample efficiency, dueling networks to separate state-value and advantage estimation, multi-step returns to reduce bias, distributional RL to learn full return distributions rather than just expectations, and noisy networks to replace epsilon-greedy exploration with learned stochasticity in the policy. The dueling architecture splits the network into two streams: one estimating the state value $V(s; \mathbf{w}, \alpha)$ and another estimating action advantages $A(s,a; \mathbf{w}, \beta)$, combined via $Q(s,a; \mathbf{w}, \alpha, \beta) = V(s; \mathbf{w}, \alpha) + A(s,a; \mathbf{w}, \beta) - \frac{1}{|A|} \sum_{a'} A(s,a'; \mathbf{w}, \beta)$. This decomposition accelerates learning in environments where many actions share similar values by allowing the value stream to learn state quality independently of action-specific advantages.

Multi-step returns blend TD and Monte Carlo methods by bootstrapping from $n$ steps ahead rather than one step ahead. The $n$-step Q-learning target becomes:

$$G_t^{(n)} = r_{t+1} + \gamma r_{t+2} + \cdots + \gamma^{n-1} r_{t+n} + \gamma^n \max_{a'} Q(s_{t+n}, a'; \mathbf{w}^-)$$

This reduces bias by incorporating more actual reward signal before bootstrapping, at the cost of increased variance and delayed updates. Typically $n=3$ provides a good balance. For environments with sparse rewards, larger $n$ can propagate reward signals backward through longer trajectories more quickly than single-step methods.

Distributional reinforcement learning, exemplified by C51 and QR-DQN, learns the full distribution over returns rather than just the expected value. C51 represents the return distribution as a categorical distribution over fixed support $\{z_1, \ldots, z_K\}$, learning probabilities $p(s,a) = [p_1(s,a), \ldots, p_K(s,a)]$ where $p_i(s,a)$ represents the probability that the return equals $z_i$. The Bellman update becomes a distribution transformation: the next-state distribution is shifted by the reward and scaled by $\gamma$, then projected back onto the fixed support via $\mathcal{T} Z(s,a) = R(s,a) + \gamma Z(s',\arg\max_{a'} \mathbb{E}[Z(s',a')])$. This richer representation captures return uncertainty, multimodal reward distributions, and risk-sensitive policies.

The deadly triad—bootstrapping, function approximation, and off-policy learning—creates instability when all three components interact. Bootstrapping introduces bias because the target depends on current estimates. Function approximation introduces generalization errors where updates to one state-action pair affect values everywhere. Off-policy learning samples transitions from a distribution that differs from the distribution induced by the target policy, violating the on-policy assumption underlying convergence proofs. When combined, these factors can cause divergence: the function approximator may amplify errors, bootstrapping may propagate those amplified errors, and the off-policy distribution may concentrate updates on states where errors are largest.

Addressing divergence requires either constraining the function class, modifying the update rule, or carefully controlling the policy distribution. Least-squares TD methods like LSTD and LSPI compute updates in closed form by solving a linear system, guaranteeing convergence for linear approximators but scaling poorly to high-dimensional features. Gradient TD methods like GTD and TDC adjust the update direction to follow the true gradient of the projected Bellman error, ensuring convergence at the cost of doubled sample complexity. Importance sampling reweights off-policy samples to correct the distributional mismatch, but introduces high variance that often degrades practical performance.

Practical implementations of Q-learning for high-dimensional control tasks require careful attention to network architecture, hyperparameter tuning, and computational efficiency. The DQN architecture typically uses convolutional layers for image-based tasks, processing stacked frames to capture temporal information. Frame skipping—executing the same action for $k$ consecutive frames—reduces computational cost and provides implicit temporal abstraction. Reward clipping—capping rewards to $[-1, +1]$—prevents large gradients from destabilizing training in environments with variable-magnitude rewards. Adam optimizer with learning rates around $10^{-4}$ provides fast convergence while maintaining stability.

Exploration strategies beyond epsilon-greedy include entropy regularization, which adds an entropy bonus to the objective to encourage stochastic policies, and curiosity-driven methods, which provide intrinsic rewards for visiting novel states. Count-based exploration maintains density models of the state space and provides bonuses inversely proportional to visit counts, encouraging systematic exploration. UCB-based methods maintain uncertainty estimates via ensembles or Bayesian approximations and select actions that maximize an optimistic value estimate.

The interaction between the replay buffer and non-stationary target values introduces subtle failure modes. If the buffer is too large, it may contain many obsolete transitions sampled under outdated policies, slowing adaptation. If too small, it may not smooth the distribution sufficiently, causing training instability. Mixing on-policy and off-policy samples in the buffer can improve stability: reserving a portion of the buffer for recent transitions ensures some on-policy signal while retaining the distributional smoothing benefits of older data.

Catastrophic forgetting—the tendency of neural networks to overwrite previously learned knowledge when trained on new data—poses particular challenges in continual learning settings. When the task distribution shifts or new skills are learned, the network may forget previously mastered behaviors. Elastic Weight Consolidation (EWC) addresses this by adding a regularization term that penalizes changes to parameters important for previous tasks, estimated via the Fisher information matrix. Progressive networks grow new sub-networks for each task while retaining and freezing previous sub-networks, enabling forward transfer without forgetting at the cost of linearly growing network capacity.

For deployment in resource-constrained environments, model compression techniques reduce network size while preserving performance. Knowledge distillation trains a smaller student network to mimic a larger teacher network's Q-values, transferring the teacher's generalization without the computational overhead. Quantization reduces weight and activation precision from 32-bit floats to 8-bit integers, decreasing memory footprint and accelerating inference with minimal accuracy loss. Pruning removes low-magnitude weights, producing sparse networks that can be efficiently executed on specialized hardware.

The evaluation of Q-learning agents requires careful experimental design to disentangle algorithmic improvements from hyperparameter tuning and random seed variation. Training curves should report mean and standard deviation over multiple seeds, ideally at least ten. Evaluation should occur on separate episodes with greedy action selection to measure learned policy quality without exploration noise. For environments with stochastic dynamics, multiple evaluation rollouts are necessary to obtain stable performance estimates. Comparing algorithms requires matching computational budgets: counting environment interactions rather than wall-clock time ensures fair comparison when algorithms have different computational costs per update.

Debugging Q-learning implementations demands systematic hypothesis testing. If the agent fails to learn anything, check that the reward signal is non-zero, that the network receives gradient flow (using gradient norm logging), and that the target values are computed correctly. If learning plateaus prematurely, inspect whether exploration has decayed too quickly, whether the replay buffer is too small, or whether the network architecture has insufficient capacity. If training diverges, reduce the learning rate, increase target network update frequency, or reduce the discount factor. Visualizing Q-value distributions and TD errors across state space can reveal pathological behaviors like overestimation or biased value estimates concentrated in specific regions.

The transition from research prototypes to production RL systems introduces engineering challenges around inference latency, fault tolerance, and online adaptation. Batched inference amortizes network evaluation cost by accumulating multiple environment steps before a forward pass. Asynchronous execution pipelines separate environment interaction, experience collection, network training, and policy updates into parallel processes communicating via shared buffers, maximizing hardware utilization. Checkpointing strategies must balance recovery capability with storage overhead: saving full model checkpoints at regular intervals enables rollback but consumes significant disk space, while saving only optimizer state allows resuming training but not policy evaluation.

The asymptotic performance of Q-learning algorithms ultimately depends on the expressiveness of the function approximator, the coverage of the replay buffer's state distribution, and the alignment between the inductive bias of the architecture and the structure of the value function. Linear approximators converge reliably but cannot represent complex value surfaces. Neural networks can represent arbitrary functions but require careful regularization and hyperparameter tuning. The choice between model-free methods like Q-learning and model-based methods that learn environment dynamics depends on the relative difficulty of value function approximation versus dynamics modeling, the availability of simulators for planning, and the computational budget for both training and inference. For tasks with high-dimensional observations but low-dimensional action spaces, Q-learning often excels. For tasks with complex dynamics but discrete state spaces, model-based dynamic programming may be more sample-efficient. Understanding these architectural tradeoffs enables practitioners to select appropriate algorithms and allocate engineering effort to the bottlenecks that most constrain performance in their specific deployment context.
