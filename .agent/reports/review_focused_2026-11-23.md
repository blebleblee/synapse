# Focused curriculum review, 2026-11-23

Read-only review of 26 public courses (alphabetical from `arts/`, plus 3 computing test courses). Nothing in `topics/` was changed. Raw reports: `.cache/reviews/*.json` (git-ignored; local only).

## Method

The full review (`learning_engine/reviewer.py`, "ruthless auditor" prompt) was measured first on 12 computing courses: ~70 findings per course, about 45% nitpicks (edge cases, hardening, notation), and Gemini's hidden thinking was 94% of the output tokens, so a course cost about as much as generating it (~$1.7). The focused prompt asks only for:

- **fact**: false statements, invented APIs / flags / functions / papers;
- **code**: code that fails as written (missing import, undefined name, syntax, wrong call);
- **truncated**: empty or cut-off sections;

at most 8 per 12k-character part, thinking off, JSON `{"errors": [{type, quote, problem, fix}]}`. On 3 comparison courses it returned ~16 findings per course, nearly all real, but missed some the full review caught (recall is lower).

Reviewers: `gemini-3.6-flash` (25 courses, old proxy, until its credit ran out), `claude-sonnet-5-5` (1 course, aerolink, until the gateway dropped the model). `thinking: disabled` was honoured only sometimes.

## Results

- 329 findings: 267 fact, 51 code, 11 truncated.
- Tokens: 1,185,367 input, 453,189 output (of which 410,953 thinking) — about 45,591 input / 17,430 output per course.
- Not yet fixed. A fix should rewrite only the affected sections, one finding at a time, and be re-checked.

Free complement (no model): `synapse lint` now reports `PYTHON_SYNTAX_ERROR` and `MISSING_IMPORT` (PR #6): 30 + 37 in the public curriculum.
